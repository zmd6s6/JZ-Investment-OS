## 用户可见路径

1. 在资产组合或观察清单登记目标标的，在人工行情保存本人有权使用的人民币报价、来源和业务时间。
2. 从导航「机会漏斗」、设置的「有限范围机会漏斗」或产品进度中进入 `/opportunities`。
3. 搜索并点击标的，明确组成「本地手选有限范围」，填写范围名称与出处；不会自动将搜索结果或整个目录加入。
4. 指定报价与基础事实的来源名称，读取人工报价绑定Evidence；换标的清空上一标的事实草稿，重读报价或换来源清空同口径确认。
5. 填写事实出处、行业、自然年年度、本期 / 上期营收、归属普通股股东年度利润、年报披露的年度稀释EPS、前收盘及其时点、停牌状态、EPS / 股价口径和四个业务时间，明确保存。
6. 年报只支持完整自然年合并人民币口径。金额为元，EPS为元／股；上期营收指上一个完整自然年。季度 / TTM / 其他币种或EPS与股价口径无法核对时留空，不能假装已核对。
7. 明确输入本次查询的最低利润率、增长、最高年报PE、最低价格变化、可选行业及候选上限。比例使用小数，如0.1为10%；这些是单次检索条件，不激活或修改Policy / Strategy。
8. 点击「运行本次确定性筛选」，查看基础资料 → 财务 → 行业 / 增长 / 估值 → Timing → 候选上限各层原因与缺项；结果自动滚入视野，长页操作反馈保持可见，可手动隐藏。
9. 展开来源，核对Evidence / hash、出处、观察 / 生效 / 可获取 / 入库 / 到期时间；刷新URL或点最近20次历史只读查看原快照，不重跑、不改旧结果。

缺失、过期、未来、损坏或口径无法核对时在对应层停止；不补零、不默认FX、不向旧数据或其他源回退。
输入校验失败保留内容；15秒超时释放按钮，结果未知时同内容重试使用原请求ID和原as_of，避免重复效果。跨币种明确缺FX，事实保存禁用。

## 确定性与来源

使用类型化Universe / Facts / Market / Run ports，基础设施只通过application向内依赖。生产报价复用已合入201；没有DSA私有依赖或新的网络适配器。
人工Facts经既有规范化、Evidence与ResearchArtifact仓库路径进入同一UOW，同时写请求回执Event、Audit和Outbox。payload包含instrument、全部业务时间及expires参与hash，不改变旧Evidence语义。
请求级事务咨询锁、标的行锁与来源hash去重；同ID异内容拒绝、失败全部回滚。筛选运行也经同事务咨询锁写不可变Event / Audit / Outbox，不增表或迁移。
读取明确来源在as_of已入库的最新事实，再判断可用性；observed / effective / available / ingested不得晚于as_of，到期失效；最新资料不适用时不借旧版。
行业也来自有出处的Facts，不把当前目录行业当历史证据。人工EPS必须完整年度、同股份 / 股价口径并绑定当前报价Evidence；0 / 负EPS或无法核对不计算PE。

固定公式版本 `manual-screen-v1`：

- 归属年度利润／营收；
- 本年度营收／上年度营收−1；
- 同口径人工价格／正年度稀释EPS（非TTM）；
- 人工价格／前收盘−1，前收盘必须早于报价观察时点。

计算使用固定38位、ROUND_HALF_EVEN上下文与十进制字符串展示，不受进程全局Decimal精度影响，不使用float或LLM。
每次冻结查询版本 / 规则hash、实际来源Evidence / 内容hash、输入与as_of。按价格变化降序、市场 / 代码 / UUID稳定打破平手，候选服务端硬上限20；没有综合投资分数或交易动作。
