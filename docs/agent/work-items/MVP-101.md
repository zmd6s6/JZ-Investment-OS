## 用户可见操作

1. `/portfolio` → 填组合名称、币种和现金 → 创建并选中组合。
2. 填标的代码 / 名称、长期与机动数量、各自均价与理由 → 保存 → 刷新仍能载入编辑与核对分仓；更新现金后刷新仍保留。
3. CSV内容先预览。无效行必须显示原因并禁止确认；与已有持仓冲突须明确选跳过 / 替换 / 累加。预览期间持仓不变；确认后查看逐行before / after与审计标识，刷新可查导入历史。
4. `/watchlist` → 搜索本地目录并选择标的 → 添加 / 刷新 / 重复添加 / 移除。未分析时生命周期、逻辑、新鲜度与下次监控条件明确未提供，不生成假值。
5. `/#policy` → 核对实际API返回的当前版本、状态、TEST_DEFAULT警告和缺失限额 → 勾选“我已阅读”；只有本地界面确认，不改变政策。

失败时：负数等输入错误显示可操作中文提示并保留字段；无效CSV行或未选冲突策略不能确认。
切组合或编辑CSV后，迟到预览不能恢复按钮；改动后须重新预览与明确选冲突策略。
确认已发给A后切到B，不会改变请求目标；A的迟到对账 / 错误不会作为B结果呈现。回A可查真实持久化历史，确认期间新填写CSV也不会被清空。
