## 范围和可见入口

`/decisions` 首次读取最多100条，点击「加载更多」到达更早记录。列表显示原始读取范围与去重后记录数，筛选仅作用于已读取范围。并发新增可能跨页重复或暂缺，页面明确提示刷新重查。点击原记录后地址保存 `decision_id`，刷新即独立读取该原记录，即使它不在首100条中。首屏列表失败时，合法精确ID仍可独立读取原详情。

详情沿用原冻结链、证据、Sizer、当前资格和人工历史。勾选核对原记录后才可发起当前后端允许的批准、拒绝、撤销或手工成交事实登记。手工事实需要真实输入数量、价格、费用、时间和凭证说明，提交后重新读取原历史。历史定位不改变TTL、Policy或Risk Veto，也不提交订单。过期、Veto、TEST_DEFAULT和legacy原记录继续失败关闭或只读。

分页失败清空旧详情和确认，中文提示后可明确刷新恢复；迟到读取不能替换新选择。缺失、非法ID和坏协议显示中文失败，不泄漏原始异常。加载中的控件和无当前合法动作的表单不可执行。该项适配P7人工复核、Beta8–10/16及既有ADR0043/0049，不增加写接口、迁移、依赖或运行时任务。
