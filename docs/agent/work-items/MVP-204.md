## 已实现

- 影子模型提案与最终确定性裁决分开；按保存的gate/outcome/reason解释结果，Risk UNKNOWN/Sizing BLOCKED不冒充PASS/0股建议/可审批Decision。
- 任一事实/理由引用可点击打开并聚焦本次Evidence；来源/出处、观察/生效/可得/摄入时间、expiry、hash、质量分及当次有效性可核对。未知或不在快照内引用明确标记，未来/过期资料不冒充可用。
- 资料正文按有界纯文本渲染，不执行HTML/Markdown、不自动访问来源；过长/格式不可读明确提示。资料始终不可信。
- 冻结Core/Tactical数量与成本、现金、参考价来源/Evidence、NAV、policy版本及hash独立可读；数值来自已保存确定性产物，不在浏览器重算。
- 已保存Thesis版本、支柱/催化/风险/证伪/监控与引用；缺正文/引用不齐明确未提供，不临时生成VALID论点。
- 确定性特征快照/version/hash及实际值，两轮独立角色、未知/风险、实际模型/修复/费用记录、委员会ID/冲突数量。既有摘要没有记录的观点字段不编造。
- 按章节渐进展开，证据引用打开目录后定位焦点，同一按钮重复点击可重新打开资料；移动端无横向溢出。读取失败先清空旧运行依据，错误与重读反馈明确，跨组合迟到响应隔离沿用并回归。
- 产品交付清单新增MVP-204只读入口与失败指引，装配/人工接受分开。
