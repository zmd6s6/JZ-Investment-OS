## 产品入口与可见操作

1. `/calendar` 的「每日检查与影子研究」选择已导入日历、组合全体及明确观察项，填写完整日期覆盖、来源、每日报告使用期限和授权起止。组合持仓逐项列出；不自动纳入未来新增成员。
2. 本地状态模式明确空资料/模型档案、0费用/Token；定时Shadow须逐角色显式选择模型，填写币种、单任务/UTC日Token与费用上限并独立允许出站/费用。当前外部资料费用预留未提供，data_profile_ids固定为空，只用明确来源的本地Evidence。
3. 点击「预览完整授权」查看真实来源、日历、成员、模型端点/名称/逐Token价格/生效期和预算版本。另行勾选后保存，始终暂停；核对保存快照后再次明确确认并启用。
4. 显式会话收盘后Worker生成真实TaskRun与日报；刷新可见action-required、hold/watch、新机会、Risk Veto、待处理审批、data/job degraded六节、实际Analysis链接与阶段。缺失明确NOT_PROVIDED；TaskRun成功不等于模型成功。当前Daily没有合格数值快照，模型完成仍可能UNKNOWN/BLOCKED与DEGRADED，不能解释为风险PASS。
5. 独立暂停或永久撤销；已出站调用可能收费，确认后后续调用被阻断。撤销同schedule不可恢复；需要新的明确授权时新建暂停任务。刷新保留原报告与输入，不重放历史未知费用。

失败可见：缺范围/资料/日历/价格/预算、授权过期/撤销、成员或来源漂移出现具名代码；越界覆盖整项拒绝、输入保留、不创建授权或Analysis。当前组合账本明确CURRENT_BOOK_READ_NOT_HISTORICAL_CLOSE_SNAPSHOT，business_as_of/knowledge as_of/记录时间分开，错过原业务日只本地报告，不补发收费研究。

## 实现与边界

- 类型化Daily DTO/应用端口；9个正规表、版本CAS、UUID幂等、不可变关系/报告/授权/意图与事务Audit/Event/Outbox；0022父为真实0021。
- 配置读写及每次模型调用拥有真实SQL权限围栏；最终HTTP前在credential/budget await后重核时限，已知未出站拒绝释放预占。原203档案/预算、205角色失败与数值门保留。
- 用数据库实际FK+父/子行锁防新持仓phantom及改删，日历指针共享锁与替换线性化；不使用全表锁。相同组合写入可能等待当前有限调用，锁序/超时需随实现复审。
- intent先持久后标准Analysis唯一队列；未知提交不自动重发，只读核对原request。终态追加报告，同内容不制造新版本。保留期过后停止正文展示，不删除审计历史。
- 没有实盘订单、批准、执行、Strategy/Policy激活、真实参数选择或Owner实例操作；auto_trade=false。Owner 18102/15433不变。
