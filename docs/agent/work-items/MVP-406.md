旧授权详情显示原ID、当前version、范围、日历与暂停/撤销状态。独立勾选核对后才可暂停或永久撤销，原version和request UUID经既有CAS/幂等门禁提交；随后读取当前详情核对。失败清空旧动作对象并显示中文提示；刷新不写业务记录，也不启用研究。新配置的创建、启用仍沿用原403完整授权预览与独立确认，不扩大成本或范围。

日报审计仅列ID、时间、状态、hash、关联配置/任务。可使用期内按ID读取真实原报告六节及业务/知识时点。正文过期或hash/Schema失效拒绝展示，仍可见允许的审计元数据。未知投资栏目明确未提供，LOCAL TaskRun成功不代表风险通过或投资判断。
