## 用户操作

入口 `/analysis`，主导航和设置均有链接。先登记组合、持仓或观察标的，在设置启用模型、填凭据/单价/预算。

1. 选组合及持仓/观察标的，也可从本地目录搜索；填写人工参考报价的明确来源名称。
2. 明确统一应用一个模型到全部角色，或展开逐角色设置。不会改全局角色映射，不静默换模型。
3. 勾选已有有效Evidence；过期/未来/无效仍列出状态且不能作为当前事实。也可选择最多3个已启用研究源，输入查询并单独同意数据调用，每源最多5条。
4. 核对预算币种/单任务及每日剩余边界、最多42次有界模型请求，并同意把证据/持仓/现金发给所选模型及可能费用，才允许发起。
5. 看真实QUEUED/RUNNING、冻结/Features/Thesis/首轮/第二轮/Portfolio/Risk/Sizing/CIO与最终闸门记录；角色观点、来源、修复、耗时、引用可直接阅读，不要求用户解析JSON。结构化原始诊断仅为可选。
6. 当前Risk与完整Sizing缺项时显示DEGRADED、UNKNOWN、无数量和具体缺口；CIO乐观BUY不能通过确定性闸门。没有必要角色有效输出时FAILED且没有影子结论，不伪造WATCH。
7. 刷新页面，从所属组合历史重读；取消只停止后续步骤，不能撤回已发出的调用或费用。重试是新请求/新Run，重新同意、保留原历史。排队久未运行提示核对Worker，不假报成功。
