# MVP-202 — 确定性参考估值与SizingContext

## 范围与限制

主规范§2.2/2.3/10/11/16、PRODUCT-06范围4–6与验收3–7，ADR0003/0006/0007/0011/0038/0039。
P5当前现金/分仓与版本在REPEATABLE READ只读事务中捕获，不伪造历史持仓。按显式MANUAL_MARKET/source_name读取截至捕获时可得报价，Decimal精度80计算分仓金额/NAV/现金比例/行业与总净暴露；缺一价不给完整NAV或任何组合比例，异币种整组FX_REQUIRED。零NAV不给比例，零数量不强制补造报价。

规范输入包含持仓成本/版本/标的、政策具体版本/配置/hash、来源Evidence/hash与所有时间、公式版本；输出给出输入和结果hash供203固定引用。只读请求不创建历史Decision或PositionSizingRun，后续实际分析必须冻结本输入，不能以重新读取“当前状态”替代历史引用。

人工报价非交易级，SizingContext永远列明缺少历史波动/流动性/相关性/风险预算/待执行容量/Risk/Thesis/公式输入；不填默认0/1，不构造SizingRequest、不运行完整Sizing、不输出建议数量/BUY/ADD。政策缺失/模糊/TEST_DEFAULT/版本或批准不完整亦阻断。本项不完成P6分析、模型运行或人工接受。

## 用户可见路径

入口 `/valuation`（导航“估值对账”、产品进度与验收页）。

1. 到资产组合录入现金和分仓；到人工行情为每个持有标的保存有效CNY报价，使用同一明确来源名称。
2. 选择组合，填完全相同的来源名称，点击“读取估值与缺口”。等待时按钮反馈，不自动调用网页/模型。
3. 核对现金、分仓数量/成本/参考市值、NAV、行业/总暴露、捕获UTC时间及报价Evidence与业务时间。
4. 阅读仓位计算缺口与政策版本；估值成功不等于Risk PASS或可交易。
5. 刷新后明确重读；选择组合或修改来源后旧结果清除，迟到响应不得污染新目标。

合成示例：现金100、Core10/Tactical2、价19.25→Core192.5/Tactical38.5/市值231/NAV331；成本11/13单独展示，不拿成本替代参考价。
缺价/过期→无完整NAV；USD组合→缺FX、无估值；服务失败→中文重试提示且保留来源输入。只读，无Policy/订单/批准写入。
