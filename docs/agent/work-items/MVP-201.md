## 用户可执行路径

从「设置与提供方」点击「记录人工行情／查看单币种与FX边界」，或从导航 / 产品进度进入 `/market-data`。
先在组合 / 观察清单登记标的，再搜索选择人民币标的，填写来源名称、可核对出处、精确价格、观察 / 生效 / 可获取 / 到期时间。
点击「明确保存人工报价」，获得Evidence ID、内容摘要和实际入库UTC时间；再点击「读取指定来源报价」，核对完整来源及业务时间。
刷新会按URL恢复本地标的 / 来源；再次明确读取可看到已持久化结果。URL不携带价格、凭据或原始来源正文。
输入按浏览器时区转换UTC。人工资料始终标注「未经独立核实、非交易级」，不会访问所填网址、启用网络提供方、调用模型或生成订单。

失败可见：错误保留输入；请求进行中显示反馈并禁用重复提交；15秒超时释放按钮，保存结果未知时同内容重试使用原request_id核对。
新内容使用新请求ID。缺失 / 过期 / 当时尚不可用 / 损坏分别呈现状态，不显示参考价；跨币种显示FX_REQUIRED，不默认1:1、不以零补价。
未装配服务显示不可用且不能保存；产品进度只说明当前构建及服务装配，不代表供应商健康或人工验收通过。

## 工程与接线

类型化 `MarketDataPort.get_snapshot` → 应用服务校验目标 / 币种 / as_of → 生产组合根注入SQL适配器 → 独立router → 真实页面。
人工保存通过同一UOW写Evidence、来源工件、请求回执Event、Audit与Outbox。请求级事务咨询锁与标的行锁保护并发；同ID异内容冲突，失败整批回滚。
Evidence的规范payload包含标的及所有时间（含到期）参与hash，不修改既有Evidence含义或旧normalizer语义；旧历史不会覆盖。
读取先选指定来源在as_of已入库的最新记录，再核对hash / 来源 / 时间及可用性；最新记录不可用时不向旧价或其他源回退。
支持CNY单币种；异币种标的、估值基准或含非零外币持仓的组合失败关闭。保存报价不会解除Risk / Approval，也不把人工数据自动升级为已核实市场事实。
无新表、迁移、生产依赖或投资参数变更；没有Worker专属任务；本项同步事务只写持久Outbox，不宣称新增消费订阅或已送达下游。未实现独立完整分析消费链，该能力由MVP-202及后续项接入。
