# 中文文档索引与同步规则

本目录承载英文原始文档的中文版本。中文版本面向项目使用者；英文原始记录保留用于追溯已接受 ADR、历史阶段承诺和外部工具兼容性。

## 权威与同步

1. `INVESTMENT_OS_MASTER_SPEC.md` 已是中文，是项目宪章的最高权威。
2. 对已接受 ADR、历史阶段契约和运行手册，英文原始记录仍保留为可审计来源；中文版本不得改变其约束力度。
3. 若译文出现矛盾、遗漏或歧义，以主规范、已接受 ADR、活动阶段契约和根 `AGENTS.md` 的优先级处理，并在发现时同步修正译文。
4. 新增或变更文档时，必须同时更新中文原文或在下表登记相应中文版本；不得把翻译当成降低治理要求的理由。
