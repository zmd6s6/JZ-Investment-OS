# ADR-0032 — 分析引用到已保存证据的只读核对

- 状态：Accepted（P6既定证据追溯与阅读体验范围内的工程决策）
- 日期：2026-10-23
- 补充：ADR-0003、0010、0018、0026；不改写旧ADR

## 决策

报告中的证据引用可打开只读资料查看器。应用端口按运行ID和证据ID读取，必须先核对不可变输入快照hash、
标的 / 时点及证据成员身份，再读取该ID的原始不可变Evidence。不扫描近期列表代替历史ID，不获取网页、不调用来源或模型。

核对快照来源 / 时间 / 内容hash，并按既有normalize_artifact口径重新计算存储正文hash。
损坏或跨标的内容拒绝；不属于该运行的证据返回404。没有快照的旧运行明确NOT_RECORDED；
旧元数据不足以核验正文时仅显示SNAPSHOT_ONLY，不用当前设置补历史；记录缺失显示CONTENT_UNAVAILABLE。
只有匹配时才返回VERIFIED，含保存的文本片段。VERIFIED仅证明存储内容和本次引用一致，不证明事实真实、模型阅读了全文或可交易。

只返回标题与白名单summary / snippet / text / content / description文本，不回传任意payload或凭据 / 元数据配置。
单片段上限20000字符、总正文上限64000字符，超长明确标注截断。页面按普通文字呈现，不执行HTML / Markdown脚本。
来源URL只在用户明确点击且为无内嵌认证的HTTP(S)时打开，使用noopener / noreferrer，不自动联网；非法定位保留文字提示。

分别展示分析当时新鲜度和当前读取时新鲜度，旧资料过期仍可审计读取，不修改历史状态，也不据此允许重新分析或提高暴露。
查看器有15秒读取期限、处理中 / 失败 / 重试、关闭与Esc、焦点回到引用；切换运行 / 引用或关闭后丢弃旧响应。
重试只读GET、不重新运行分析；报告、主表观点、风险引用与输入快照共用同一查看入口。

## 替代方案、兼容与恢复

拒绝只展示UUID、用当前网页替换历史正文、返回任意JSON、将整个资料库开放成运行引用，或让模型补写缺失原文。
新增版本化GET，不改旧路由 / Prompt / AgentOpinion / 投资规则，无迁移或新依赖；读取不写审计 / Outbox或业务状态。
回滚API / 页面保留所有Evidence、报告、快照与历史；所有者实例部署仍须新的明确授权。

验证覆盖引用成员 / 双重内容校验、旧运行 / 缺失 / 损坏 / 过期与未来可用时间、非近期资料、鉴权、零写入、HTML / URL安全、
有界读取与迟到响应、返回报告 / 刷新不重跑模型，以及390px可操作。仍不代表P6或正式Decision完整链已完成。
