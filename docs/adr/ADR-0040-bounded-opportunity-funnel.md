# ADR-0040 — 有限研究范围、人工基础事实与确定性机会漏斗

- 状态：Accepted（MVP-402授权范围内工程决策，不修改投资治理）
- 日期：2026-10-27
- 相关：ADR-0001 / 0003 / 0008 / 0010 / 0015 / 0016 / 0038；PRODUCT-08与Beta第13节。

## 决策与明确边界

首版没有获授权market universe。页面必须显著区分「本地手选有限研究范围」与「全市场证券全集未提供」，不把目录或Watchlist冒充全市场。
采用typed Universe / Facts / MarketData / FunnelStore端口；市场报价复用已合入201。人工基础事实通过规范ResearchArtifact / Evidence、来源工件及审计持久化，不允许用户填写PASS或模型编造指标。
事实包含营收本期 / 上期、净利润、股数、前收盘及其业务时点；确定性Decimal计算利润率、营收增幅、PE与相对前收盘变化。不存在财报/历史行情供应商时仍可由所有者录入自己有权使用的资料；资料始终人工提供、未经独立核实，不成为交易级事实。
筛选阈值由用户在本次研究查询中明确输入并随运行冻结；它是检索谓词，不修改Policy / Strategy / 风险规则，不允许据此产生BUY / ADD或改变生命周期。
漏斗按基础资料 / 报价与币种 → 财务 → 行业 / 增长 / 估值 → Timing → 有界候选执行；缺项 / 过期 / 未来 / 损坏在对应层明确未提供，不能用evidence-count-v1冒充财务指标。
稳定排序只用于研究队列，不产生综合投资分数；候选硬上限20。本项没有已装配完整P6深研编排器，生产明确停在「深研未提供」，不以假结果完成，不扇出任何模型。未来深研端口只能接收已经过漏斗的有界候选，仍须授权与预算。

## 持久化 / 时间 / 重放

规范payload包含instrument、全部业务时间与expires参与hash，不改旧Evidence语义。保存Facts、工件、回执、Audit / Event / Outbox同一UOW；请求ID同内容重放，同ID异内容拒绝，失败全部回滚。
机会运行复用只追加Event作为版本化输入 / 结果快照，不增表；来源、as_of、实际入库、规则、输入Evidence / hash、每层理由 / 缺项和候选上限随运行冻结。读取不能重算或覆盖历史。
as_of不允许未来；数据必须observed/effective/available/ingested均不晚于as_of且未到期。明确来源读取先取最新记录再判有效性，不借旧价或换源；前收盘时点必须早于参考报价观察时点。
人工事实不会触发网络请求、修改投资政策、创建Decision或执行交易；auto_trade=false。

## 验证与恢复

同一生产API / DB / UI用合成输入分别验证正常有界候选、数值不满足被排除、缺项 / 时效 / FX失败可见；并发 / 幂等 / 回滚 / 不可变 / 有界成本具名测试。不得用只有fake port的单测冒充生产正常路径。
无新迁移或生产依赖；回滚应用 / 页面，保留已追加证据与运行审计。Owner实例、真实源或付费模型未获本项额外授权，不操作。

## 实现期口径澄清

只支持自然年完整年度（本期fiscal_year、上期fiscal_year-1）合并人民币数据、归属普通股股东年度利润与年度稀释加权平均股数；不是TTM、季度利润或无来源人工盈利预测。
行业也须来自该时点有来源Facts，不用当前目录行业冒充历史证据。报价与股数须明确同股份 / 股价口径且绑定当前Quote Evidence；不能核对即缺项，不硬算PE。
公式采用固定38位ROUND_HALF_EVEN上下文，查询包含固定rule_set_version及规则hash；外部Decimal全局配置不能改变结果或排序。此澄清不新增真实阈值或修改投资政策。
