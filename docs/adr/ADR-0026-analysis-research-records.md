# ADR-0026 — 分析研究主表原子记录与只读追溯

- 状态：Accepted（P6 既有范围内的工程决策）
- 日期：2026-10-21
- 补充：ADR-0003、0004、0005、0006、0008、0018、0019、0023、0024；不改写旧 ADR

## 背景与决策

原 AnalysisRun 保存报告摘要，却未接通已有委员会、Agent 和 Risk 主表。
本纵切保存实际运行的结构化结果，不从报告自由文字重建、不重新调用模型。

- 完成时将实际两轮委员会、各角色请求与校验后的观点、失败状态、精确运行时间、风险评估及正规化证据关联写入已有主表。
  原始模型输出只保存原有 hash，不保存凭据或自由文本日志。Portfolio / Risk 是下游角色，不冒充第三轮辩论。
- 最终报告、研究主表、关联回执、审计 / Outbox 在同一 SQL 事务提交。后台先锁运行并核对工作者与取消状态；
  取消 / 旧工作者不发布完成工件。持久化失败回滚全批，运行明确失败，不重放付费请求。
  同步提交回执丢失时重新读取已经发布的原终态，不把已成功提交的报告改成失败；晚到写入不改已关联研究的终态。
- 新增只读、版本化研究记录接口，从只追加关联回执读取实际主表 ID；不根据当前模型 / 政策 / Thesis 补历史。
  旧记录未保存主表时明确 NOT_RECORDED；读取不执行投资治理、批准或模型调用。
- Risk 的 UNKNOWN / VETO / PASS 与有效期原样保留。veto=false 不表示 PASS，过期不改历史判断，也不构成当前授权。
- 当前独立 StrategyVersion 未装配，正式 InvestmentDecision 暂不创建；只读界面明确 NOT_REGISTERED 与缺口。
  不放宽正式 Decision 的外键，不伪造已批准政策 / 策略，不把影子建议说成待审批或成交。

## 替代方案、兼容与恢复

拒绝把所有内容仅留在报告 JSON、另建万能业务表、拆分成功报告与工件事务，或给缺失外键填随机 UUID。
复用现有主表及不可变守卫，无新迁移 / 依赖 / Prompt / AgentOpinion 输出协议变化。
内部结果增加可选完整工件；旧测试 / 历史结果不被补写，不称作主表已关联。
API / Worker / 页面同步交付；回滚前处理活动任务，保留主表、回执、输入与审计，不删除历史。
本轮仅命名隔离库和合成模型验证，不部署所有者实例；正式部署仍须独立备份 / 重启授权。

## 验证

覆盖真实结构化工件 / 证据关联、重复终态、取消竞争、事务回滚、Risk UNKNOWN / VETO、旧报告不追补、读取鉴权与页面反馈。
