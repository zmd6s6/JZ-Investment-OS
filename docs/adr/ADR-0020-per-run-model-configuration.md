# ADR-0020 — 单次分析模型选择与配置固定

- 状态：Accepted（主规范 §2.3、§6.5、§17.5 与 P6 既有范围内的工程决策）
- 日期：2026-10-20
- 补充：ADR-0004、0010、0013、0014、0018、0019；不改写既有 ADR

## 背景与决策

旧队列只固定资料与组合，模型网关每次调用重新解析角色映射，排队或阶段之间改设置可能静默换模型、价格或端点。
本次先交付单次模型配置纵切；多研究来源顺序、完整 Policy / Strategy / Prompt 版本和主表关联仍为 P6 后续。

- 启动窗口读取无网络副作用的模型选项：沿用当时角色映射，或明确选择一个已启用、有凭据引用的兼容模型用于八个分析角色。不自动启用模型，不修改全局映射。
- UI 提交选项摘要，入队前重算；摘要不一致拒绝，要求重新核对。不让客户端提交可信配置、价格、端点或凭据。
- 固定各角色档案 ID、名称、模型、超时 / Token 上限、定价版本 / 币种 / Decimal 单价 / 生效时间与配置 hash。端点只参与 hash，不复制至快照；密钥及 credential_ref 不进入快照或队列。
- `AnalysisRequest` 增加可选版本化 `model_plan`，保存于既有受守卫的队列和不可变 input_snapshot；旧 JSON 仍可解析、旧报告不补写。公共 API 是 additive 选项读取及可选选择字段，不改变 AgentOpinion、Prompt 或 Decision Schema。
- 执行前核对全部固定档案；网关每次调用（包括修复）再按固定 ID 验证，不解析最新映射。档案、端点、参数或价格改变 / 档案停用、删除、凭据缺失则失败关闭，不切换来源。修改角色映射不影响已入队任务。
- 凭据不固定：执行时仍通过当前 SecretStore 引用读取，允许正常轮换，不缓存旧秘密、绕过停用或使用已移除引用。调用已发出后不能撤回，保留既有取消与费用边界。
- 预算仍在每次调用前按当时有效的任务 / 当日门禁预留；不能利用快照恢复较宽预算。固定价格需与当前配置相同，否则拒绝，不能悄悄改价。
- 显式重新发起仍是新运行，重新核对原证据并固定当时模型配置；不复用旧运行的配置授权。页面说明这一点。

## 替代方案与后果

不选择执行时静默追随当前配置；也不复制密钥或在停用后继续使用旧端点。配置修改可能使排队任务失败，需要用户重新确认，换取可解释的模型 / 成本边界。无新增生产依赖或数据库表。
本轮不是完整模型供应商版本仓库，快照固定配置内容和摘要，不能保证供应商别名背后的权重永久不变；报告仍区分配置模型和提供方实际返回模型。

## 安全、兼容与回滚

读写沿用本机会话 / Bearer / CSRF 控制，不增加授权或真实模型调用。仅用合成网关 / MockTransport 和命名隔离库验证。
旧待执行任务若没有 model_plan，新生产 Worker 明确标失败，不使用当前映射自动补全；历史报告继续读取。
新旧 API / Worker 不得混合部署；部署前检查队列并同步更新。回滚先停止入队、处理或取消新版待执行任务，再同步回滚 API / Worker；保留快照 / 阶段 / 审计，不降级或删历史。旧代码可能忽略新增请求字段，不能让旧 Worker 消费新版任务。
