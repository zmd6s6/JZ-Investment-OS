# ADR-0039 — 冻结的参考估值与失败关闭 SizingContext

- 状态：Accepted（MVP-202既有主规范与ADR0007/0038约束内工程决策，不改变投资治理或真实参数）
- 日期：2026-10-27
- 补充：ADR0003、0006、0007、0011、0038；不取代旧ADR。

## 决策

提供独立只读估值上下文，不把参考估值冒充交易或完整Sizing。PostgreSQL REPEATABLE READ / READ ONLY事务冻结P5现金、Core/Tactical数量/成本/版本/标的分类以及政策身份；引用当前数据库快照，不提供伪造历史持仓时间旅行。捕获时间独立列明；行情业务as-of为该捕获时间，所有available/ingested/expiry约束仍由MarketDataPort检查。

显式选择source/source_name，逐标的读取，不静默回退。只支持CNY单币种，出现实质异币种持仓或异币种现金基础币种时整组FX_REQUIRED；不设1:1。人工未核实行情只用于参考估值，trading_grade=false不可提升。

纯函数以固定Decimal精度80计算分仓金额、NAV=现金+持仓市值、权重及行业/总净暴露（当前长仓账本）；金融输入禁止float，最多1000行且38位输入边界。缺一笔有效价格即不给完整NAV/任何组合权重，不把缺项当零；零持仓允许不需要报价，零NAV不给比例。金额保留精确乘积；循环小数比率仅在精度80舍入，不用于执行数量。规范输入快照、市场Evidence/hash/所有时间、政策版本与配置hash、公式版本及输出hash对调用方可见，以便203固定引用；本只读请求不产生历史Decision/SizingRun，不改写历史。

SizingContext始终列明缺失历史波动率、流动性、风险预算、相关性、待执行/批准未成交容量、Risk/Thesis及公式输入；没有完整受校验来源不构造SizingRequest、不调用Sizing引擎、不生成目标数量/BUY。Policy缺失/模糊/TEST_DEFAULT/批准或版本配置无效也失败关闭。不能因参考NAV可算即声称风险通过。

## 替代 / 影响

拒绝平均成本代替市场价、固定波动率/容量、默认为零预占、LLM心算或人工报价交易级升级；拒绝为此只读切片新增生产依赖/表/迁移。既有PortfolioSnapshot与SizingRun由后续实际分析持久化，未来增强应保留版本与冻结输入。

## 安全 / 恢复

无网络/模型/订单/批准/Policy写入；删除新增只读入口即可回滚，无迁移，不改变P5账本与报价历史。测试使用15440/18112独立合成栈，Owner实例不操作。正常、缺失、时间、币种、Decimal、hash、并发一致读取和真实浏览器可见失败必须验证。
