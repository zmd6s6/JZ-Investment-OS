# ADR-0034 — 显式多来源研究预览批次

- 状态：Accepted（既有 P6 与 ADR-0015 / 0018 内的工程实现，不改变投资治理或数据授权）
- 日期：2026-10-23
- 补充：ADR-0015、ADR-0016、ADR-0018；不改写已接受 ADR

## 背景

研究端口和持久化预览已支持多个档案，但页面一次只能保留一个预览；逐源保存还会覆盖先前的分析勾选。
需要让使用者明确选择多个来源、核对成本和结果，再将自己确认的资料交给团队。

## 决策

- 页面选择一个主来源和默认不选的附加来源，最多五个、每源数量乘来源数最多五十条。
  展示完整顺序、每源结果上限与独立计费提示；改变查询、数量或来源须重新确认。
- 复用现有单来源预览 API，浏览器按显式顺序串行发送，每源一个独立 UUID。
  这不是失败回退：成功、空结果或失败都不会添加未选来源；失败不取消其他已明确选择的查询。
- 每源结果、错误或结果未知分别显示。成功结果不被后来的失败覆盖，内容不被合并为可信事实。
  同源不同档案也不等于独立证据，不自动裁决矛盾、提升来源等级或增加置信度。
- 请求开始前将全部预览 ID 放入当前地址；刷新只通过受保护 GET 找回，最多五项，不重发查询。
  未找到结果不证明没有外部调用或费用；页面离开后不再开始下一来源，已经发出的请求可能继续。
  这是页面驱动批次，不是后台队列，不保证刷新后自动完成尚未发出的来源，也不保证供应商侧 exactly-once。
- 每个来源独立勾选和确认入库，复用服务端十分钟窗口、源状态、新鲜度、幂等及事务约束。
  **不存在跨来源全有或全无事务**；部分保存成功必须保留，失败来源只读找回核对，不重放查询。
- 保存后的分析勾选按证据 ID 并集合并，不覆盖其他来源；分析仍须明确选择组合并确认模型费用。
  超过五十条禁止启动，不静默截断；可以清空勾选但不删除已存资料。
- 读取沿用现有十五秒客户端期限及迟到响应隔离；期限不取消后台供应商调用、不自动重试。

## 替代方案与后果

不新增批量后端、数据库表或任务服务，避免把网络调用纳入长数据库事务，也避免增加后台自动费用路径。
代价是跨来源分别确认、未保存的勾选仅驻留页面；刷新可找回服务器保存的预览和已确认回执，但不恢复未保存的勾选。
未来真正后台聚合或跨源确认需另立兼容、成本与恢复契约，不由本页面推断交付。

## 安全与运维

仅选择已启用、有凭据且 registry 支持研究检索的档案，不启用、不测试连接、不复制凭据。
公开查询仅发送到明确所选档案，不发送组合、成本或现金；外部内容仍普通文本呈现。
五个上限是页面请求规模保护，不是投资参数。真实供应商许可和调用仍须既有人工授权。

## 迁移与回滚

无公共 API / 数据库 / Prompt / AgentOpinion / Decision Schema、依赖或投资规则变化。
回滚仅恢复前端构建；保留全部预览、确认、证据和审计。旧页面只识别首个 preview_id 时，其他资料仍可在证据库读取。
本次不自动部署到所有者 18102，不沿用已使用的重启授权。
