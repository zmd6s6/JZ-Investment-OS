# ADR-0025 — 人工投资逻辑工作台与原子保存

- 状态：Accepted（主规范与 P6 既有范围内的产品 / 持久化工程决策）
- 日期：2026-10-21
- 补充：ADR-0001、0003、0006、0008、0010、0017、0018、0024；不改写旧 ADR

## 背景

分析已能固定既有 Thesis，但用户没有页面建立或修订这些记录。
不能用占位逻辑或任意模型文字填补缺口，也不能让旧编辑器覆盖后来保存的版本。

## 决策

- 新增只读 workspace 与显式保存版本的接口；用版本化、拒绝未知字段的应用 DTO 和类型化端口。
  页面提供标的、摘要、状态、带逐条证据引用的支柱 / 催化剂 / 风险、失效条件、监控项和修订原因。
  不调用供应商，不改 Policy / Strategy、持仓或交易批准；运行时模型工具仍不能访问写接口。
- 新建默认 UNKNOWN，可由用户明确选择 VALID；不替用户选择具体投资哲学或逻辑内容。
  修订遵守现有领域状态机，BROKEN 恢复需要完整复核，本页不提供快捷恢复。
  保存的状态是人工研究判断，不是投资授权；既有风险、证据和策略门不变。
- 每次保存提交 request_id 与必填、可为空的 expected_version_id。空基准仅允许首次创建；
  旧版本不匹配时拒绝整次写入并保留浏览器草稿，不自动合并或取最新覆盖。
- 请求级事务咨询锁确保同 UUID 串行；标的行锁串行化人工首次创建 / 修订，最终仍使用 Thesis 当前指针 CAS。
  与已有自动写入竞争时，CAS / 唯一约束失败整批回滚并明确冲突，不静默覆盖。
- 复用既有 Thesis writer 的语义 diff / 内容 hash / 正规化引用写入，允许其参与调用者工作单元而不提前提交。
  ThesisVersion、当前指针、保存回执事件、审计与 Outbox 同一事务；记录的 before 为实际基准 hash。
  没有实质内容变化时保留原版本，不制造空版本。
- 幂等回执保存在已有只追加事件表，仅含请求摘要、基准 / 结果 ID 与版本 hash，不保存正文或密钥。
  同请求同内容返回原回执；不同内容或不同标的拒绝复用。成功回执重放不重新判断已过去的资料到期时间，也不再写版本。
  事件是命令回执，不替代 Thesis 主表，未新增通用 JSON 业务表或数据库迁移。
- 写入时服务端确定 UTC 时间；所有主张必须关联本标的或明确通用、已入库且当前新鲜的证据，最多50个独立引用。
  客户端不能提交可信来源等级、时间、hash 或正文。缺失、跨标的、未来、陈旧、到期和重复引用失败关闭。
- 页面有读取 / 保存反馈和有界等待；不自动重试写入。未确认结果再次提交相同内容时复用请求 ID。
  历史只读展示内容 / hash / 父版本和语义 diff，可从研究页进入，并回研究页单独确认费用后分析。
  后续修订不改变已冻结的运行或旧报告。

## 替代方案与后果

拒绝直接编辑历史版本、只有内容去重而没有基准保护、在两个事务分别保存版本与回执、
或另建账号 / 数据库 / 消息服务。新页面与状态机严格，冲突需人工核对，不擅自恢复 BROKEN。
本轮是人工维护闭环，不是自动团队 Thesis 生成；完整 Risk / Decision 主表、策略和 P6 其余验收仍待完成。

## 安全、兼容与恢复

沿用本机会话 / Bearer、同源 / CSRF；请求未知字段与越界内容拒绝，不信任外部文本为指令。
无新依赖、迁移、Prompt / AgentOpinion 变化或实盘路径。旧查询接口保持兼容，OpenAPI 同步生成。
撤回新路由 / 页面即可回滚应用；保留版本、引用、回执和审计，不删历史。
测试仅用命名隔离库与合成内容；所有者实例部署 / 重启仍需单独明确授权。
