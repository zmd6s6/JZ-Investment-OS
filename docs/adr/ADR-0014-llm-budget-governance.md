# ADR-0014：LLM 成本与 Token 预算门禁

- 状态：已接受
- 日期：2026-09-22

## 决策

所有真实模型请求必须在应用层先取得不可超卖的预算预留。预算策略、模型定价和账本任一不可用时，网关失败关闭，绝不发送网络请求。预算同时覆盖单任务累计 Token/成本与 UTC 日累计 Token/成本；同一 `request_id` 的修复尝试属于同一任务累计。

定价由所有者通过模型档案配置，包含币种、输入/输出 Token 单价、版本和生效时间；实现不得硬编码任何提供方价格。预留与日/任务账本在同一数据库事务、行锁下更新。响应中可验证的实际用量会结算为追加式 `llm_usage` 记录，并把预留转换为已消费；调用失败或用量不可验证时保留预留，采取保守计费。

## 后果

模型连接测试也是模型网络请求，因此同样受预算和定价门禁约束。默认 UI 值 `TEST_DEFAULT` 仅供测试配置，未保存不代表有有效预算。真实网络验证仍须由所有者用合成 Evidence 和其自行录入的凭据执行。
