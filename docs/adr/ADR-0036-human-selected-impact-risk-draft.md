# ADR-0036 — 人工勾选支柱挑战形成风险草稿

- 状态：Accepted（既有P6人工草稿与追溯范围内的工程决策）
- 日期：2026-10-26
- 补充：ADR-0025、0028、0035；不改写旧决策

## 决策

只读影响核对之后，允许用户明确勾选已匹配冻结支柱的WEAKEN / BREAK判断，把完整理由与证据加入当前风险草稿。
这是待核对的模型意见，不是事实裁决；不修改原支柱、摘要、全局状态或投资授权。加强 / 无改变、无基准、未匹配、旧响应无选择ID只读。
矛盾判断保留，不自动投票或产生状态。风险可人工编辑 / 移除，最后通过既有保存按钮、证据门、CAS及状态机生成版本。

影响选择ID由实际观点ID与原集合索引派生；来源命令兼容增加impact_ids，旧观察选择仍可使用。
观察与影响合计最多20条、不可重复且不可全空；页面每轮草稿选择观察带入或风险带入，风险总量超过20或完整文字过长均拒绝，不截断。
服务端核对实际主表 / 运行、标的、冻结基准、选择ID及影响类型和匹配状态；不信任客户端提交的理由或“已匹配”标记。
来源只表示人工曾核对，不保证人工编辑后的内容逐字等于模型判断，沿用ADR-0028语义。
影响选择与实际观点ID写入原只追加回执，与版本 / 审计 / Outbox同事务；不保存模型正文到事件。

## 兼容与恢复

仅应用命令 / 读取响应的兼容扩展，不改运行时AgentOpinion、Prompt、Decision、数据库或依赖。
旧观察命令仍按原规范化字段计算请求摘要；无来源命令不变。旧回执缺impact_ids默认空，成功请求重放先于新鲜度和基准校验。
旧前端可忽略响应新字段；旧API不接受新影响命令，前后端须同步升级。撤回应用保留版本和全部来源历史，不删除数据。
本轮隔离合成环境验证，不操作18102，不调用真实提供方。完整团队生成摘要 / 语义修订、正式Decision与完整Sizing仍是独立缺口。

## 验证与依据

覆盖稳定ID、空 / 重复 / 总数边界、未知选择 / 错误类型 / 旧基准拒绝、旧命令摘要、来源回执重放与事务回滚。
页面覆盖默认不选、过期资料禁止带入、保留人工内容、草稿无写入、明确保存 / 刷新及来源回看。
主规范§2.2、§2.3、§6.3、§9；PRODUCT-06验收2 / 5 / 7。没有新投资规则或自动状态转换。
