# ADR-0023 — 分析的政策、公式与 Prompt 版本快照

- 状态：Accepted（主规范 §2.3、§6.5、§7 和 P6 既有范围内的工程决策）
- 日期：2026-10-20
- 补充：ADR-0003、0004、0006、0007、0011、0018、0019、0020
- 取代范围：政策仅保存显示标签、Prompt 仅按角色 / 版本名称生成摘要的旧实现；不改写已接受 ADR 或旧报告

## 背景

原分析读取最近的 ACTIVE 政策名称，但计算使用测试上限与公式。名称不是配置，也不构成人类批准；
排队期间修改政策或代码还可能让报告标签与实际输入不一致。

## 决策

- 准备分析时保存版本化治理快照：具体政策 ID / 版本 ID / 文档 / 内容摘要 / 生效与批准信息、完整公式参数、各角色 Prompt 的实际内容摘要与工具白名单。
  沿用 input_snapshot 与任务请求的不可变守卫，不新增表或迁移。当前没有装配独立 StrategyVersion，明确标 NOT_CONFIGURED，不伪造关联。
- 先选择组合绑定的政策；未绑定时才允许全局唯一 ACTIVE 回退。全局无 ACTIVE 时使用仓库发布的完整 TEST_DEFAULT 文档。
  绑定失效、多 ACTIVE、版本缺失 / 跨政策、文档不合法 / 摘要不符、批准主体或时间缺失、未来生效均拒绝；不悄悄选择最新或切回测试政策。
- ACTIVE 需要版本元数据明确 approved_by_actor=HUMAN，具名 approved_by / approved_at，并满足 approved_at <= effective_from <= as_of。
  旧 ACTIVE 记录缺少这些信息时不推定已获批准；本轮不补批准、激活或更改真实参数。
- 政策摘要使用规范化配置的 SHA-256；唯一集合字段 require_thesis_states 排序，防进程哈希种子导致版本摘要漂移。
  历史版本摘要不兼容时拒绝，不原地改写；后续治理创建新版本，不伪造批准。
- 任务执行使用已冻结的政策配置和公式，不再借用当前标签配测试上限。后续政策指针变化不改旧研究的含义。
  快照仅适用于本次只读影子研究，不是执行授权；未来批准 / 执行仍须独立检查有效政策和输入。
- 当前公式仍是既有 TEST_DEFAULT 参数，独立 StrategyVersion 尚未装配，因此任何政策名都不能使 BUY / ADD 或新暴露通过政策门。
  本轮不选择真实 intent 权重、公式系数、风险预算或流动性参数；剩余真实估值 / 特征缺口仍留 P6。
- Prompt 摘要来自实际系统指令、角色、版本和工具白名单，不再仅 hash 一个名称。文本不变，不激活学习提案。
  执行前比较当前 Prompt / 公式工件与冻结内容；变化则在付费调用前明确失败，不拿新代码覆盖旧快照。
- 新生产 Worker 遇到没有治理快照的旧排队请求失败关闭；历史报告继续读取且不追补。
  用户明确新建运行时重新读取当前政策 / 工件，旧记录不变。Agent 输入包含固定政策，不包含批准人姓名等无关个人信息。
- 政策审阅接口与分析复用同一类型化读取端口；可按组合查询。页面区分当前政策与运行当时的快照，展示测试限制，不新增治理写入口。

## 替代方案与后果

拒绝只保存名称 / UUID（无法说明实际使用参数）、执行时重读最新配置（改变历史）、复制真实密钥或自动创建批准。
冻结增加少量 JSON 存储；升级代码可能使旧队列失败，必须由用户核对后明确新建运行，不能自动重放付费调用。
这不是完整 Strategy / Thesis / Risk / Decision 主表链路交付，也不保证模型供应商权重版本不变。

## 安全、迁移与回滚

无新依赖、数据库迁移、真实投资参数选择或交易路径。验证仅用合成配置、网关与命名隔离库。
同步更新 API / Worker；回滚前停止入队，处理或取消新格式任务。保留治理快照 / 审计和历史，不让旧 Worker 忽略新字段消费。
正式实例部署 / 重启仍需单独授权，不沿用先前已执行的授权。
