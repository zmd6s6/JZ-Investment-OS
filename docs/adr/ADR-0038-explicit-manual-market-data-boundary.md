# ADR-0038 — 显式人工行情快照与单币种边界

- 状态：Accepted（MVP-201既有授权范围内工程决策，不改变投资政策）
- 日期：2026-10-26
- 补充：ADR-0001、0003、0007、0010；不改写旧ADR或未合并PR #18。

## 决策

当前Release无已授权可调用的结构化行情源，不能用博查文字或合成价格伪造报价。
先提供可替换MarketDataPort与真实持久化的MANUAL_MARKET适配器；用户可经设置入口手工录入自己有权使用的报价、出处、观察 / 生效 / 可用 / 到期时点。
这不是自动供应商接入、已核实市场事实、全市场universe、FX、历史波动率、流动性或完整Sizing。

报价使用字符串精确Decimal、UTC业务时间；每次保存生成只追加MARKET Evidence与来源工件。
保存回执 / 审计 / Event / Outbox同事务；相同请求复用，已使用请求ID不同内容拒绝，版本与资料历史不覆盖。
服务端核对标的与币种，来源选择显式且精确；读取按as_of限制available_at和ingested_at，不静默回退其他来源或旧价格。
过期、未来、损坏、缺失明确返回状态，不使用LLM或默认价格补齐。输入事实仍标记人工提供、未经独立核实。

首版边界为CNY单币种：异币种标的 / 组合请求FX_REQUIRED并失败关闭，不默认1:1、不心算汇率。
后续MVP-202只可经类型化端口读取带来源 / Evidence / 时间 / hash的参考输入，且仍须独立满足风险和Sizing契约；保存报价不授权投资动作。
人工报价不会自动成为已批准的交易级数据或解除Risk / Approval闸门。

## 兼容与恢复

新增应用 / API / UI，不改现有研究API或已保存Evidence含义，无新表、迁移、依赖或投资参数。
端口可替换后续获授权来源，首版不收集新网络源凭据、不自动查询。删除应用入口可回滚，保留全部报价与审计历史。
测试仅隔离合成库，不操作Owner实例；日历ADR-0037与0015迁移由MVP-401独立负责。

## 验证计划

正常持久化与刷新 / 来源追溯；Decimal / UTC / 时间边界；过期 / 未来 / 缺失 / 跨币种拒绝；请求重放 / 竞争与事务回滚；
无模型调用 / 静默回退 / 订单路径；设置入口到产品操作、可见失败及当前能力限制。
