# ADR-0056 — 每日公平扫描与历史可达

- 状态 Proposed，随MVP406独立Gate且实际合入Release后生效
- 日期 2026-11-11
- 补充ADR0008/0048，复用ADR0052的月度扫描经验，旧ADR保留

## 决策

Daily固定首50配置与最新50执行会遗漏后续配置或待收口日报。新增0026，父为实际已合入0025，只有daily_scan_cursor运行进度表。CONFIGURATION/REPORT两个主键行各保存最后检查UUID；事务行锁串行规划，下一轮从该UUID之后取最多50条，末尾回绕。配置最多计划8个任务，游标仅推进至实际检查的末项；执行收口每轮最多50条。进度不含许可或业务状态。规划提交与业务执行分离，崩溃可能延至下一轮回绕，原TaskRun/业务唯一键/最终授权锁继续防重和失效出站。

在有限记录集合及Worker持续轮询下最终检查所有记录。配置检查失败、暂停、撤销、日历及范围变化不会变成研究许可，不自动重发未知收费意图。REPORT扫描仍只读既有Analysis产物并追加日报，不覆盖原正文/hash。新进度表不替代业务Event/Outbox事务。

原列表API保留默认上界和响应数组，增加有界offset/limit与稳定UUID次序。新增单ID配置/任务/有效日报读取及日报审计摘要。offset分页是实时读取，并发新增可能跨页重复或暂缺，UI提供刷新提示；不声称整库快照或全量统计。正文到期仍拒绝，允许的元数据摘要仅含原ID、时间、phase、hash和关联，正文不从审计接口返回。UI支持旧授权详情、独立明确暂停/永久撤销，沿用版本CAS与命令幂等，失败后清空动作对象。

## 替代与影响

拒绝无限扫描、提高固定limit冒充完整覆盖、内存游标、通过读取自动重试模型或扩大授权。复用PostgreSQL，无新生产依赖，不改变Policy/Risk/审批/Strategy/交易；auto_trade=false。

## 恢复与验证

0026降级只删除可重建游标，Daily授权、执行、报告和审计均保留。游标丢失从头遍历，既有业务幂等防重复。实际升级/降级/再升级需验证。具名PG覆盖106配置/历史、51配置并发/重启、旧pending终态及原hash、读取零写入/过期/非法参数，生产API/真实Worker/浏览器验证分页、精确详情、暂停/刷新和失败恢复。最终证据以功能PR实际HEAD为准。
