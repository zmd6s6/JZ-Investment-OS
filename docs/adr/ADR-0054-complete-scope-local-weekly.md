# ADR-0054 — 完整来源声明的本地周筛选 v2

- 状态：Proposed（须独立Gate及实际合入后生效）
- 日期：2026-11-09
- 补充ADR0008/0045/0046/0051，不修改投资治理或既有v1协议。

## 决定

PRODUCT08范围2/4/7与主规范§14/17/S12允许零出站的本地周筛选续接。新`/api/v2/opportunities/weekly`只接受明确schema2.0保存请求，原v1仍按200成员限制且不能读取/控制v2配置。v2冻结已经保存的完整筛选run、原声明快照id/hash、全部精确成员、用户查询条件、候选上限、显式日历版本及1–52完整自然周。每次新修订默认暂停；另行核对并明确启用。模式请求沿用不改变的v1启停字段，路由和配置版本隔离。日历指针变化停止旧配置，不猜测缺失交易日或自动延长覆盖。

周结束后使用最后明确会话收盘时点，完整读取同一冻结快照全部成员（最多1000），复用ADR0051一次全局排序最多20。来源当时尚未入库/可得、身份变化、配置/日历变化都失败关闭，不截断或拼子集；资料缺失保存逐层缺项。显式完整日历中无会话的周记录SKIPPED_CLOSED，不伪造完整筛选结果。历史成员不会自动更新为后来市场全集。

## 事务、隔离与恢复

复用现有配置/revision/member/result表，用schema2.0、独立任务与命令命名空间隔离；v1视图/Worker只消费schema1.0。全局配置容量仍50，保存时同事务咨询锁串行检查；不增加数据库迁移或生产依赖。冻结完整模板使用独立typed模型，不扩大FunnelQuery或把1000成员转换成v1 FunnelRun。

完整筛选prepare只读，持久化端口增加同UOW写入方式；可靠TaskRun、v2正规来源/Event、周结果、审计与Outbox一次提交。失败全部回滚，失败TaskRun保留且最多3次后续重试。配置revision+自然周幂等，暂停/修订与任务同配置行锁线性化；暂停成功后旧计划不能提交。合成专属时钟只属于E2E启动脚本，不成为生产设置或Owner任务授权。

## 安全与替代

固定零外网/模型/费用，不消费研究intent，不自动深研或扇出。候选后续研究仍逐次明确同意；SOURCE_DECLARED/UNVERIFIED、market_universe=NOT_PROVIDED、auto_trade=false及批准/Risk/Sizing闸门保持。拒绝直接扩v1、分批top20拼候选、跨事务半产物、日历猜测和自动费用调用。

验证覆盖201/1000完整成员、正常/缺项/前视/闭市、幂等、Outbox回滚、暂停/换日历竞态、协议隔离和真实合成API/DB/Worker/UI。回退应用前暂停v2配置，保留所有只追加历史，前向修复；无Owner实例迁移或真实激活。本纵切不宣称完整市场、402/P8或Owner产品接受。
