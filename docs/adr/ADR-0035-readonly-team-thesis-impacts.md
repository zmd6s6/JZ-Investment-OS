# ADR-0035 — 团队支柱影响判断只读核对

- 状态：Accepted（既有P6研究追溯范围内的工程决策，不改变投资治理）
- 日期：2026-10-26
- 补充：ADR-0024、ADR-0026、ADR-0028；不改写原决策

## 背景与决策

AgentOpinion主表已保存thesis_impacts，但研究读取投影未返回，人工工作台只能看到一般观察。
复用实际主表与冻结Thesis，不新增模型调用或从自由文字补造影响。

- 研究读取增加原保存的thesis_impacts；团队整理响应增加可选默认空的impacts集合，最多展示100条，超出明确标注。
- 返回角色、轮次、观点ID、支柱键、加强 / 削弱 / 击穿 / 无改变判断、理由与有效运行引用。
  所有引用必须属于当次输入；最新第二轮失败不复用首轮判断，缺字段旧响应不补造历史。
- 支柱只匹配当次冻结版本的键，并展示当时主张与状态；未匹配或无版本明确区分，不按当前版本或文字相似度套用。
- 这是不可信模型判断的只读核对，不是事实成立、共识或状态转换。矛盾保留、不投票，过期历史可读但不放行新分析。
- 不增加采纳影响 / 写状态接口，不改原观察勾选、保存来源、CAS或批准门。完整团队修订仍未交付。

## 替代方案与后果

拒绝让LLM重新生成历史判断、自动映射相似支柱或将BREAK直接写成BROKEN。
代价是使用者仍须自行核对与编辑；界面明确说明不是自动修订或投资批准。

## 兼容、安全与回滚

只读响应兼容扩展，不改变AgentOpinion运行时输出、Prompt、Decision、数据库表或依赖。
旧响应缺impacts由页面说明，旧服务不提供本功能；新响应格式错误拒绝采用，不静默转自由文字。
引用文本普通显示；不调用外部来源，不写Thesis / 审计 / 投资状态。回滚API / 页面保留主表与全部历史。
正式部署仍需新授权；本轮只在隔离合成栈验证，不操作18102。
