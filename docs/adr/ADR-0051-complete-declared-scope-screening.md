# ADR-0051 — 来源声明快照全成员筛选协议 v2

- 状态：Proposed（随本工作项通过独立 Gate 并合入后生效）
- 日期：2026-11-06
- 补充 ADR-0003/0040/0044/0045；仅取代 ADR-0046 对新 v2 全成员扫描不能处理 201–1000 成员的工程限制。v1 路由、200 项限制与 201 项拒绝保持原样，已有运行与 hash 不改写。

## 问题与决定

来源声明快照允许最多 1000 个成员，但 v1 的200项筛选上限导致更大的声明集合无法完整筛选。v2 仅接受既存快照 ID/完整 hash 和显式查询，不接受子集；在逐一核对来源三业务时间、服务器入库时间、实际身份和全部成员后，使用同一 as-of 和原 v1 确定性公式评估每个成员。每行保留原行情/事实及其 Evidence、来源、四时间、hash、所有阶段原因和缺项；先完整计算所有成员，再按价格变化降序、市场/代码/UUID升序进行一次全局稳定排序，最终最多20名。未命中资格的成员和超过候选上限的合格成员均保留可审计原因。禁止逐批截断或用分批候选拼接代替全局排序；任何身份缺失或漂移整次失败，不保留半成品。

协议、事件与结果独立版本化为 v2；同请求和同快照精确重放，跨版本重用请求编号或同编号不同内容失败关闭。结果、正规快照关联、Audit/Event/Outbox 同事务；故障回滚、保留旧历史。原 v1 结果读取仍使用原格式，不能被 v2 降级解析。空 as-of 首次成功时服务器时间固定，重试返回已保存结果。无新迁移或新依赖；回退应用时保留已有只追加事件与来源关联，勿删除历史，采用前向修复。

## 边界与替代

只使用已存在的本地人工行情及年报，不从 locator 访问外网，不调用模型或付费服务；不得通过全市场模型扇出、生成投资建议或交易。SOURCE_DECLARED/UNVERIFIED 只说明用户提交的声明，不代表来源授权、独立核实或真实市场覆盖；market_universe 始终 NOT_PROVIDED。全市场和真实财务/Timing来源许可仍未提供。人工逐候选研究仍需现有单独授权；v2本身不创建研究、Decision、Strategy或订单，auto_trade=false。

拒绝直接放大v1字段（破坏旧200/201契约）、先分批取前20再拼接（无法作为全局完整证据）、默认填补缺失数据或把目录当成市场权威。完整1000项与各种失败/边界、重放、跨协议请求冲突、事务故障及真实合成API/DB/UI均须验证；工程证据不等于Owner部署或Checkpoint接受。
