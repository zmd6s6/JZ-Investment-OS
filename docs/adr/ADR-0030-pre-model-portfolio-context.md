# ADR-0030 — 模型前组合计算上下文与持久化特征快照

- 状态：Accepted（P6 既有输入、追溯与失败关闭范围内的工程决策）
- 日期：2026-10-22
- 补充：ADR-0003、0004、0005、0018、0019、0026、0029；不改写旧 ADR

## 决策

旧顺序在委员会后才读取价格，团队无法使用实际NAV / 分仓估值。本次将同一次显式选源取价和确定性估值放在PREPARING，
在第一个模型调用前提交真实 FeatureSnapshot 与回执 / 审计 / Outbox。同一估值供全部角色和最终报告，不再次取价。
快照范围仅为PORTFOLIO_VALUATION，不冒充完整市场指标、已授权仓位策略或正式Decision；缺价格 / FX / 特征仍明确保留。

- 不修改原不可变排队输入。新增运行时输入摘要，绑定原请求摘要、算法与完整计算结果；实际Agent / 委员会记录用运行时摘要。
  原请求摘要用于排队 / 资料 / 逻辑关联，两个摘要明确区分，不把原请求摘要冒充包含后来取得的价格。
- 输入快照独立于最终研究发布事务，成功提交后即使取消 / 模型失败 / 中断也保留。存储失败不调用模型，不自动重放行情费用。
  运行行锁、当前Worker租约、状态 / 取消校验防旧工作者追加；同内容重放复用回执，不同内容拒绝。
  租约仅在Worker装配后注入内部请求，不保存至冻结输入或发给模型，不接受持久化任务携带有效租约。
- 全部角色收到同一确定性结果及缺口；不得自行重算、填空或将其当作外部Evidence。事实观察仍须引用本次可见证据。
  不新增模型调用、不更改Prompt系统文本或AgentOpinion输出协议、不更改风险 / 批准 / 投资参数。
- 业务as_of、实际记录时间和提供方参考时点分别保存；不回填Evidence.available_at，不声称证明了真实行情发布时间或适合历史回测。
  新只读接口可在运行中 / 失败后查看已提交上下文；不触发模型 / 行情，不按当前组合补历史。
- 复用既有feature_snapshot与不可变守卫，无迁移或新依赖。成功研究主表读取同时校验上下文回执 / 内容 / 运行摘要；旧无上下文报告走原摘要兼容，不补写。

## 替代方案、验证与恢复

拒绝把模型用过的价格只留在内存或最终报告、覆盖排队快照、仅用请求摘要缓存不同报价，以及给缺失指标填默认值。
API / Worker / 页面同步更新；回滚前处理活动队列，保留快照与审计，不删除失败运行的准备输入。
所有者18102部署仍须独立授权；本轮只用隔离合成数据 / 来源验证。

验证覆盖全角色同一上下文 / 摘要、仅一次取价、提交失败零模型、失败 / 取消保留、旧Worker拒绝、并发幂等、整批回滚、
主表不可变 / 读损坏拒绝、旧报告兼容、只读鉴权与窄屏反馈。正式Decision、完整市场特征 / FX和P6整体仍待收口。
