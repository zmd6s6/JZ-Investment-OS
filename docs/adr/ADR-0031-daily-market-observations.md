# ADR-0031 — 模型前单日行情观察与精确单位

- 状态：Accepted（P6 已限定的确定性特征与只读追溯工程决策）
- 日期：2026-10-23
- 补充：ADR-0003、0007、0021、0022、0029、0030；不修改既有 ADR

## 决策与范围

在用户已明确选择的行情调用内，读取同一日线的开高低收、提供方昨收口径、成交量及成交额。
使用版本化类型、独立128位Decimal上下文计算单日涨跌比例与日内振幅，并保存标准单位和实际原始输入。
Tushare的手转股、千元转元仅在适配器完成；不把提供方百分数直接当比例，不新增历史查询或外部调用。
依据：[官方daily字段定义](https://tushare.pro/document/2?doc_id=27)（2026-10-23核对）：未复权日线、除权昨收、成交量手、成交额千元。

这是单日描述性观察，不是年化波动率、均量、可交易容量、价格新鲜度或真实发布时间证明。
不从单日数据推定仓位容量，不填默认波动率，不改变Risk、Policy、TEST_DEFAULT、Sizing BLOCKED或批准门。
未来接历史波动率须有显式历史查询 / 样本 / 复权 / 可用时间契约，不在本次偷偷扩大请求范围。

## 追溯、兼容与失败

- 通用MarketQuote可选携带标准单位日线；身份 / 时间 / 收盘价必须与参考报价一致。无扩展字段仍是合法旧式报价。
- 缺字段保留未知，真实零成交量 / 金额为零；提供的非法数值、负量、错误高低关系、身份 / 时间不一致拒绝，不偷偷删掉坏特征保留可信外观。
- 目标单日观察进入已有模型前FeatureSnapshot / 运行摘要与全部角色输入；最终报告只读展示相同内容，不二次取价。
  保存端从冻结组合和原始日线重算，不相信客户端或终态回传的衍生数值；改原始输入或特征会改变摘要。
- 新可选字段为空时不序列化，也不加入旧估值输入摘要；保留旧回执、FeatureSnapshot与运行摘要逐字兼容，不补写历史。
  有数据时字段内保存独立计算版本、输入摘要、来源 / 顺序 / 降级、参考时点与缺口；原排队输入不改写。
- 只有目标标的的单日观察进入本次估值上下文；不能据此宣称组合所有市场特征、相关性或FX完整。

## 替代方案、运维与恢复

拒绝让LLM算百分数、把振幅叫波动率、把成交额叫容量、自动拉历史或补旧报告。
无新依赖、表或迁移；AgentOpinion输出协议和系统Prompt不变，兼容扩展只读估值响应。
同步交付API / Worker / 页面；旧任务继续按既有源码指纹守卫失败关闭，不自动重放费用。
回退应用保留所有输入、观察、报告和审计。所有者实例升级仍需新的明确备份 / 重启授权；本轮只用隔离合成夹具验证。

验证覆盖单位与精确计算、缺失 / 零 / 非法输入、身份 / 时间 / 收盘一致、摘要与旧记录兼容、模型前落库 / 篡改拒绝、全部角色同一输入、只读刷新及390px。
