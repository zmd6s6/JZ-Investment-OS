# ADR-0033 — 显式目标历史日线与描述性统计

- 状态：Accepted（P6既定市场特征与显式选源范围内的工程决策）
- 日期：2026-10-23
- 补充：ADR-0003、0007、0018、0019、0021、0022、0029、0030、0031；不修改旧ADR

## 决策

启动窗口增加默认关闭的目标历史日线选择；只有选择行情档案并明确勾选，才固定目标ID到行情计划。
请求与幂等摘要包含该选择，显式新运行保留并重新确认费用，旧请求无该字段时不增加历史查询。
查询限目标标的、参考日及其前89自然日，最多90条，不查询其他持仓历史、不扩大到其他来源。
报价成功的同一适配器最多增加一次历史请求；历史失败明确显示，不为补特征再调用下一档源，不自动重试。
来源尝试账本仍是适配器批次而不是逐HTTP账单，查询说明标注历史范围；取消 / 中断不承诺无费用。
选历史时批次总等待上限为档案超时的两倍，逐HTTP仍受档案超时限制；未选时保留原批次期限。

通用类型保存原日线、请求边界、接收状态与失败代码；严格校验身份 / 非未来时间 / 日期唯一 / 窗口与参考日收盘一致。
Tushare按官方daily的ts_code / start_date / end_date请求，未复权收盘、除权昨收、成交量手 / 成交额千元；
精确转换为股 / 元。依据：[官方daily文档](https://tushare.pro/document/2?doc_id=27)（本轮核对）。
不从未复权相邻收盘推算除权收益，使用每行提供方昨收计算当日日收益。

程序对最近20条观测计算日收益样本标准差（分母n−1，不年化）、按日收益连乘的累计变化、平均成交股数与平均成交金额。
20条为描述性统计窗口，不是生效投资阈值；不足20条或字段缺失保留未知，不填零、不把缺失日期当零收益或补交易日。
每个结果保存算法版本、全部原始样本、实际时间范围 / 数量、来源 / 降级与输入hash；独立128位Decimal计算。
无法证明交易日连续、供应商真实发布时间或历史修订的时点可得性，明确标注不能用于历史回测或交易级Sizing。
这些观察不替代年化波动率、流动性容量、风险预算或FX；Sizing仍BLOCKED，TEST_DEFAULT不允许新增暴露。

同一模型前FeatureSnapshot保存并重算验证，全部角色与报告共享，不在阅读 / 刷新时取历史。
旧快照不补写，新可选字段为空不序列化，不改变旧估值 / 请求摘要。无迁移、新依赖、Prompt / AgentOpinion输出或风险授权变化。

## 替代方案、验证与恢复

拒绝默认抓历史、凭日振幅填年化波动率、用供应商百分数或LLM计算、跨来源拼样本，以及为了有结果自动拉更长窗口。
覆盖显式确认 / 幂等 / 重试、窗口 / 身份 / 数值 / 时间 / 重复、除权口径、缺样本、失败可见、模型前持久化 / 篡改拒绝、历史不变与窄屏。
同步更新API / Worker / 页面，旧任务沿用源码指纹失败关闭；回退应用保留全部快照 / 报告 / 事件，不删除或重写历史。
所有者18102升级仍需新的备份 / 重启授权；本轮只用隔离合成来源与MockTransport，不调用真实凭据。
