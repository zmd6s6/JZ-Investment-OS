# ADR-0052 — 月度任务公平有界扫描与历史分页

- 状态：Accepted（MVP-404，ADR-0050的调度补充，不改变投资治理）
- 日期：2026-11-05

先截取固定前50个启用配置会让后续UUID永久饥饿。每轮以 `monthly_scan_cursor` 单行行锁串行选择下一批最多50个配置，只将游标推进至实际检查的末项；到末尾后在本轮回绕。游标在0025独立表中持久化，多个Worker与重启共享；计划提交前崩溃最多延至一轮回绕，TaskRun的现有幂等键和报告唯一约束防重复。每轮生成的任务继续最多4个；游标不是授权、报告或投资参数。仅在没有源数据持续无限增速且Worker继续轮询时保证每个配置最终获得检查。cursor是可重建运行时状态，回滚0025只丢扫描位置，不改0024历史。

配置、任务和报告历史按固定稳定排序分页，每页分别最多50/60/60；UI显示加载更多，提醒记录并发变化后刷新重查。旧的有效报告API同样提供offset；单个冻结报告的重放及不可变历史不改变。offset列表在并发插入时并非事务快照，跨页可能重复或暂时遗漏，用户可刷新；保留逐条可达与完整历史，不静默以首页冒充全量。
