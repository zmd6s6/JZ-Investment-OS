# ADR-0018 — 研究预览、原子确认与分析输入冻结

- 状态：Accepted（主规范和 P6 已授权范围内的工程决策；不改变投资治理）
- 日期：2026-10-15
- 补充：ADR-0001、0003、0004、0015、0016；不改写已接受 ADR

## 背景

原页面在查询时立即写 Evidence，且分析默认读取最新资料，用户不能核对后选择，也无法解释一次运行实际用了哪些输入。

## 决策

- 新增 PostgreSQL 预览与确认表；预览只作为不可信候选，不进入 Evidence 或分析。预览、确认记录均只追加。
- 查询显式指定单个档案与标的。服务端使用 UTC 时间；候选 available_at 不早于本次获取完成时间，保留更晚的上游可用时间，不延长上游到期时间。
- 预览可确认窗口为 10 分钟（工程防误用期限，不是投资参数），以服务端时间判定。供应商保留期限仍独立有效。
- 客户端提供 UUID 请求标识；同标识同请求重放返回原预览，不重复查询；不同请求拒绝复用。PostgreSQL 事务咨询锁串行化同标识，不新增服务。
- 查询响应丢失时可按预览 ID 读取；不自动重发付费调用。若上游已调用但事务提交失败，无法保证供应商侧 exactly-once，必须提示风险，不自动重试。
- 确认仅提交预览 ID、标的 ID、候选 ID；不接受客户端回传或修改正文、来源等级、时间、hash。过期 / 未来候选不能入库，来源停用时拒绝新确认。
- 确认锁住预览，所选候选整批写入 Evidence、研究工件、审计 / 事件 / Outbox 与确认记录；同事务全部成功或全部回滚。相同集合重放返回原结果，修改集合返回冲突。
- 旧 ingest / fetch 接口保留兼容；新页面使用预览 / 确认流程。预览与确认不调用模型。
- 分析请求可显式提交证据 ID 集合：缺失、空集合、跨标的、未来或过期输入失败关闭，绝不补入其他证据。省略字段保留旧接口的有界自动读取。
- 在模型调用前冻结证据 ID / hash / 来源 / 业务时间、组合快照和政策标签，并保存版本化 input_snapshot。终态保留该快照；数据库禁止修改已经存在的快照，旧运行不追补。
- 将本次涉及的分析输入数据库读取移到基础设施，应用通过类型化端口访问。AgentOpinion、Decision、Prompt 与投资风险规则不变。

## 替代方案与后果

不采用进程内缓存（重启丢失），不让浏览器回传可信正文，不增加签名密钥或独立缓存服务。
新建两张小表与约束，增加一次页面确认；通过“保存所选并继续分析”保持连贯，不自动跳过模型计费确认。
本轮仍不实现多源自动回退、后台调度、取消 / 重试 / 重启恢复的完整分析作业。

## 安全与运维

预览和分析输入受既有鉴权保护。普通审计 / Outbox 只包含 ID、计数和 hash，不记录密钥或正文；供应商文本仅以普通文本呈现。
预览不是已核实事实，确认不提升来源等级，也不授权投资、模型预算变更或交易。

## 迁移与回滚

前向新增表、只追加触发器以及 AnalysisRun 输入快照守卫，不改历史 Evidence / Decision。
回滚应用时保留新增表和历史数据，旧接口仍可读写不带快照的运行；已冻结快照必须继续保留。
仅空表允许降级删除新增表；存在预览 / 确认历史时拒绝破坏性降级，采用前向修复。覆盖空库升级、上一版本升级、守卫和回退兼容测试。
