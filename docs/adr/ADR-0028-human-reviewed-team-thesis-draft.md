# ADR-0028 — 团队观点辅助草稿与人工采纳来源

- 状态：Accepted（P6 既有范围内的产品与追溯工程决策）
- 日期：2026-10-22
- 补充：ADR-0003、0004、0005、0010、0017、0018、0024、0025、0026；不改写旧 ADR

## 背景与决策

已有分析与人工投资逻辑工作台，但用户需手工搬运团队观点，保存后也难以回到实际来源。
本纵切串联只读来源、草稿编辑与既有人工版本保存，不增加新的模型调用，不自动修改 Thesis 状态。

- 成功运行且具备可核对研究主表和固定 Thesis 基准时，可读取版本化团队观点整理视图。
  只用实际主表结构化 observations；同角色有第二轮时用第二轮，最新失败不复用首轮冒充成功。
  观点仍是不可信模型判断；保留最新未知项、历史 Risk gate 和来源标识，不宣称共识或当前批准。
  不从自由文字或旧摘要补造逻辑，不执行 Prompt 中的指令。
- 页面从报告进入工作台，默认全不勾选。明确勾选才把观察加入当前编辑草稿为“受挑战”支柱，
  不替换摘要、不提高 / 恢复逻辑状态。重复内容不重复加入，支柱上限不静默截断。
  新建仍默认 UNKNOWN，用户必须填写长期判断并明确保存；离页未保存的内容不宣称持久化。
- 来源视图最多100条观察，超出有明确标记；一次最多20条采纳选择。当前列表缺失 / 不新鲜资料不可直接勾选。
  基准与当前版本不一致禁止直接套用，提示重新核对 / 明确新分析；不偷偷读取最新基准替换旧来源。
- 保存命令新增可选 review_source（运行ID / 观察选择ID），不是可信结论。服务端校验成功运行、
  实际主表、标的、冻结基准和选择归属，并使用既有当前指针 CAS、当前证据门和合法状态机。
  人工可以编辑或移除草稿内容；来源记录表示曾核对的观点，不是模型逐字撰写或全盘赞同。
- 来源运行 / 输入hash / 选择与观点ID仅写只追加保存回执，不把模型正文复制进审计 / Outbox。
  与 Thesis、证据关联、指针、审计 / Outbox 同事务；无实质变化仍不制造空版本。
  workspace 可回溯这些人工整理来源；不修改旧版内容hash或已保存分析。
- 请求回执先于来源再校验，成功重放不受后来到期影响；无来源字段的旧命令摘要保持不变。
  页面未知结果复用原请求ID，不自动重新调用模型或提交写入。

## 兼容、替代与恢复

新增只读 GET thesis-review、可选保存来源与只读历史来源字段，无新表 / 迁移 / 依赖或 Agent 输出协议变化。
拒绝直接将模型观点变成 VALID / BROKEN、自动复写当前 Thesis、静默合并冲突、借测试策略登记放行交易。
自动团队 Thesis 生成 / 语义影响裁决、正式 Decision 完整链仍未交付，不将本纵切标成 P6 整体完成。
回滚应用保留所有版本 / 来源回执 / 输入 / 审计，禁止删除历史或降级数据库。
仅使用命名隔离库和合成模型验收，不部署所有者实例；部署仍需新的明确授权。

## 验证

覆盖无副作用读取、真实来源 / 引用、旧记录与失败角色、跨标的 / 旧基准 / 伪造选择拒绝、
CAS竞争、整批回滚、回执重放及旧摘要兼容；浏览器覆盖勾选前无写入、人工编辑保存、来源回看与历史不变。
