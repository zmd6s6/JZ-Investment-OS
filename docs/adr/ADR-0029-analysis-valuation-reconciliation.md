# ADR-0029 — 分析估值对账与未知仓位输入失败关闭

- 状态：Accepted（P6 既定确定性计算与失败关闭约束内的工程修复）
- 日期：2026-10-22
- 补充：ADR-0003、0007、0011、0018、0019、0021、0023、0026；不改写旧 ADR

## 问题与决策

旧分析路径将未知行业暴露填零、风险 / 流动性容量填满、交易单位填一股，并把总持仓当成 Core。
行情结构及 Tushare 适配器还固定填入 20% 波动率。这些不是确定性计算出的事实，不能据此登记正式 Decision。

- 新增版本化只读估值对账，以本次冻结 Portfolio、现金和实际报价计算 NAV、分仓数量 / 市值 / 权重、现金占比和总暴露。
  两桶分别计算，不截断权重制造合规外观；金融数值仍为 Decimal，使用独立 128 位计算上下文，协议输出精确十进制字符串。
  固定算法版本、输入 hash、价格来源 / 顺序 / 降级和 UTC 参考时点，按标的排序保证确定性；不读取当前组合补历史。
- 校验报价身份、币种、正价格和非未来时点，包括未持有的观察标的；多币种无 FX 时不合并 NAV。
  缺持仓价格不填零；目标缺价但已持仓估值齐备时可展示已知 NAV，整体仍为 PARTIAL。
  数量真实为零可以有零市值，不把缺失价格或权重显示为零。
- 行业分布仅引用冻结持仓的人工录入分类，明确标来源；未分类保留为未知 / 未分类市值，不推定零行业暴露。
  本轮没有增加权威分类、交易日历、新鲜度、波动率、流动性、风险预算、交易单位、待执行暴露或 FX 数据源。
- 删除默认波动率及旧链的覆盖逻辑，供应商没有实际特征则为 None。当前生产仓位上下文不完整，所有动作均明确 BLOCKED，
  不调用纯领域仓位引擎、不输出建议数量、随机外键或正式 Decision；TEST_DEFAULT 新暴露门仍关闭。
  这收紧错误输入处理，不改变领域公式 / 测试政策参数、Risk Veto、人工批准或交易权限；减仓候选仍可文字展示但不伪造数量。
- 报告提供中文对账明细和具体工程缺口，无需用户再填写访问令牌。长小数只截显，技术数据保留精确字符串。
  旧报告无本版对账时明确未记录，不补算，也不把旧占位仓位数值作为完整依据；原历史 JSON 不改写。

## 兼容、验证与回滚

使用已有终态报告事务及不可变守卫，无新表 / 迁移 / 依赖 / 供应商 / Agent 输出协议。
内部 MarketQuote 波动率变为可选，旧测试链不再接受默认波动率配置；生产显式选源路径不变。
新增报告字段为兼容扩展；同步更新 API / Worker / 页面，旧队列仍按固定策略指纹守卫，不静默换代码。
回滚保留报告、输入、策略及审计，不删除历史。所有者部署 / 备份 / 重启仍需独立授权。

验证覆盖两桶精确对账、Decimal 上下文隔离、排序 / 摘要稳定、未分类、部分缺价、零持仓、非正净值、无 FX、
未来 / 错币种 / 错身份 / 无效报价、默认特征消失、仓位不调用引擎、报告持久化与只读刷新、390px 展示。
主规范 §2、§5、§10、§11、§12、§18；PRODUCT-06 范围4 / 5，验收2 / 3 / 5 / 7。
