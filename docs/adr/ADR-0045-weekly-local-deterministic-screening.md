# ADR0045 — 默认暂停的每周本地确定性筛选

- 状态：Accepted（主规范/PRODUCT08限定的工程调度，不改变投资治理）
- 日期：2026-10-29
- 补充ADR0008/0037/0040/0044；不复用STATUS_ONLY为研究许可。

## 决策

只读本地已入库行情/年报，零外部网络、零模型、零费用。用户选择既有不可变FunnelRun模板，冻结≤200人民币同市场标的/精确来源/查询谓词/≤20候选；明确选择SSE或SZSE及已导入日历版本，并确认声明区间的全部交易会话完整。区间为1至52个完整周一到周日自然周；用户声明的完整覆盖不是从缺会话推断工作日。自然周完全结束（市场时区下周一00:00）后才运行，以该周最后显式会话收盘作为as_of。确认完整覆盖但周内零会话时明确记录闭市跳过，不伪造交易日或筛选产物。

新配置版本默认暂停，启用须独立明确“仅本地确定性、无模型/网络/费用”同意。日历STATUS_ONLY开关不授权/停止本地筛选；日历来源指针更换则原周配置阻断，须选择新日历保存新版本。保存新版本始终暂停，原历史不变；模式CAS版本保护，未知写入按原request_id幂等恢复。

## 持久化与竞态

0019→0018新增正规化配置指针、只追加revision/成员和周结果。revision固定日历hash、完整覆盖及模板hash；成员外键约束标的，结果外键关联TaskRun与原漏斗Event。配置revision+业务周唯一任务/结果，暂停再启用不创建同周重复业务效果。

ReliableJobExecutor在同一UOW锁配置及当前日历、核版本后仅调用OpportunityService的只读prepare。既有FunnelRun通过同UOW保存，TaskRun、漏斗产物、周结果、Audit/Event/Outbox一次提交；故障全部回滚，失败TaskRun独立持久留痕，最多既有三次重试。准备后暂停先提交则门禁阻止；任务先锁定则暂停等待该本地事务完成，暂停成功后旧任务不能再提交。失效配置/换日历状态可见，不自动扩大范围/换源。

不消费candidate研究intent、不自动深研；候选后续仍经ADR0044逐次同意。这里只构建已有范围的每周本地筛选，不提供全市场universe、团队付费研究、投资建议/批准/订单或完整P8，auto_trade=false。

## 验证、恢复与替代

拒绝默认启用、周五/工作日猜测、缺会话推交易日、跨事务半产物、自动调用模型、静态成功和覆盖历史。正常/缺数据/闭市/未来周/暂停换版竞态/幂等/Outbox故障/迁移与真实合成API/DB/Worker/UI具名验证。

只在独立合成环境验证；Owner18102/15433与真实任务不操作。无新生产依赖。回滚应用并暂停新配置，保留全部历史；迁移只在空表允许降级，有历史强制前向修复，禁止删除历史。实际激活真实调度的范围/频率/输入许可仍须有效Owner确认，不因本工程实现获得新来源或费用授权。
