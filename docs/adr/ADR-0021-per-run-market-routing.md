# ADR-0021 — 单次行情来源顺序与尝试审计

- 状态：Accepted（主规范与 P6 已限定范围内的工程决策）
- 日期：2026-10-20
- 补充：ADR-0003、0010、0013、0015、0016、0018、0019、0020；不改写既有 ADR

## 背景

原行情装配按启用档案名称排序，并自动追加空的合成适配器。用户不能在分析前确认顺序，普通无数据与供应商错误也难以区分。
P6 要求多来源显式选择、禁止静默回退；研究文本和结构化行情仍是不同能力。

## 决策

- 启动窗口默认「不读取行情」，即使有启用档案也不调用。用户可勾选最多十个受支持的行情档案，并上移 / 下移确认本次顺序；不改全局设置，不启用档案，不自动测试连接。
- 新增只读 `GET /api/v1/analysis-market-options`；返回启用、有凭据引用且已注册类型的非敏感摘要。提交新增可选 `market_profile_ids` / `market_configuration_hash`，顺序参与幂等摘要。确认摘要过时拒绝；服务器从档案重建配置，不信任客户端提供的端点、价格或配置对象。
- 版本化 `market_plan` 固定有序档案 ID、名称、类型、超时、保留期和配置摘要，随既有受保护队列 / 不可变输入快照保存。端点只参与 hash；凭据和凭据引用不入快照。省略选择的新旧客户端均不自动加源；旧排队请求无此字段按空计划执行，旧报告不追补。
- application 定义配置与工厂端口；infrastructure 注册类型到结构化报价适配器。生产目前仅注册 `TUSHARE_MARKET`，可配置多个此类档案；不是已接入所有供应商。新增类型需实现同一端口、校验授权并注册，不引入新的生产依赖。博查仍走研究预览端口，不提供行情。
- 执行前验证整组配置；每次读取再按固定 ID 核对当前档案并读取当前 SecretStore。配置变化、停用 / 删除或凭据不可用，停止后续来源，不自动换源。轮换有效秘密无需复制旧秘密；已发上游请求不能撤回。执行中才发现秘密不可用时，前面的模型调用可能已计费。
- 只有普通供应商失败、无数据或部分缺价才尝试用户事先选定的下一项，且只请求缺失标的；报价已齐不再调用剩余项。未选源、博查、合成价格都不自动加入。每项有整体超时边界。
- 严格校验报价 ID、币种、精确正数、带时区的非未来时间及保留上界；不从模型猜价、换币或构造价格。无效批次标失败。适配器异常使用脱敏类型，不保存供应商原始错误 / 秘密；有效空响应单独标无数据。
- 记录本次实际适配器读取 / 校验的顺序、档案、查询、状态、返回 ID / 精确价格 / 币种 / 时点，随结果保存；不是每一项都必然发出 HTTP（例如不支持的市场）。审计缓冲区属于单次请求，不共享。第二档及之后的报价标 `degraded=true`；报告读历史，不查当前设置重建。
- 显式「重新发起新运行」保留原行情 ID 和顺序，重新验证并固定当前档案；禁用 / 删除不换源。需要另选来源时回研究 / 持仓入口重新确认。旧运行与审计不变。

## 时间与限制

Tushare 日线请求按 `Asia/Shanghai` 的分析业务日，返回日收盘价最早记作当地 15:00；未到该时刻不提供该日收盘价，不能再记为午夜可用。
这不是供应商真实发布时间证明，也不是完整交易日历 / 行情新鲜度策略。没有增加前一交易日查询、实时行情或自动历史补价；缺价继续失败关闭。
保留期仅作为报价年龄上界，不代表该范围所有旧报价都适合交易。真实时间可用性、波动率 / 流动性特征、FX 与完整版本链仍需 P6 后续验收；既有测试政策不因来源可配置而变成投资授权。

本次尝试记录随已完成的分析结果保存，并非逐次网络请求的持久化账本。结果保存前取消 / 进程中断可能只有冻结计划，实际尝试未完整留存；页面明确这是未知，不能当作零调用或费用为零。
逐次追加审计及该中断窗口的验收继续留在 P6，不通过恢复当前设置或猜测历史补写。

## 替代方案与后果

不采用后台按名称排序、自动发现 / 自动启用 / 静默追加来源，也不复制凭据到任务。配置变化可能终止旧任务，换取明确的授权、可解释费用与历史可追溯性。
扩展点是适配器注册，不引入微服务或通用插件执行；未配置行情仍可研究，但不能假装估值完整。

## 安全、迁移与回滚

沿用本机会话 / Bearer 与写操作保护，不拓宽数据许可或真实调用授权。验证只用合成适配器、MockTransport 和命名隔离数据库。
无数据库迁移、新生产依赖、AgentOpinion / Decision 协议或投资规则变化；新增字段为兼容性扩展。
API / Worker 必须同步更新。回滚先停止入队、处理或取消新版待执行任务，再同步回滚；旧 Worker 不得消费新版选择计划，以免忽略选择而按旧规则调用。
保留所有快照、阶段、报告与审计，不删除历史；真实部署备份 / 重启仍须单独明确授权。
