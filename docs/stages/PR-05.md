## 目标

交付安全的研究和审议纵切面。运行时角色必须经由 `LLMGatewayPort` 背后的版本化严格
协议通信；模型和外部文本在通过模式与领域验证前一律是不可信数据。委员会辩论由确定性
机制限制为两轮，保留明确异议和失败，且不得创建 Decision、批准、执行或订单。

## 验收标准

1. 不得将自由格式模型文本变成 AgentOpinion：模式无效输出最多允许两次明确修复，随后以
   `INSUFFICIENT_DATA` 失败，且不得捏造意见。
2. 每项事实观察均引用冻结上下文中可见的一个或多个 Evidence ID；未知项和假设在结构上
   区别于事实，不能伪装成事实。
3. 为审计保留角色注册、提示词包哈希、模型请求元数据、用量、延迟及经清洗的原始输出引用，
   且不记录密钥。
4. 第一轮针对同一个不可变 AnalysisContext 执行所需独立角色；冲突检测具有确定性，第二轮
   为定向执行、包含 Devil's Advocate，且任何会话不得超过两轮。
5. 超时、网关失败、供应商模式漂移、无效修复和缺失 Evidence 均为明确结果；不得静默替换为
   散文或高置信度分析。
6. 类提示词注入的 Evidence 只能作为不可信数据引用，不能改变角色、允许列表、提示词版本、
   Policy、风险、批准或执行行为。
7. 本阶段不创建 CIO 最终 Decision，也不创建批准、执行、经纪商或实盘交易路径。全部夹具为合成数据。

## 风险和人工决定

本阶段未授权任何真实供应商。实现使用合成适配器，且不选择供应商、模型、生产提示词、
预算、数据保留策略或投资治理参数。任何非合成使用前，这些选择均需要人工授权。

### 范围决定 — 2026-09-20

人工批准将 S1/S2 最终 `WATCH`/`AVOID` Action 断言延后至 PR-07。Master Spec 将最终建议
归属 CIO，而 PR-07 负责 CIO/Decision 路径；因此 PR-05 仅保留这些场景的研究与委员会前置
条件的合成夹具。这保留了 PR-05 对创建 CIO Decision、批准、执行或实盘交易路径的明确禁止。
