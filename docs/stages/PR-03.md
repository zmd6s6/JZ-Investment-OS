## 目标

引入可替换的研究提供方边界和证据优先的摄入纵切。外部 payload 保持不可信数据：上游 Schema 漂移和失败必须失败关闭，历史记录保持可读，初始特征集由确定性代码而非 LLM 推导。

## 验收标准

1. 提供方 adapter 只暴露内部带版本 DTO；DSA 私有 type、table 或 module 不得进入 domain 或 application 代码。
2. 有效合成工件规范化为不可变、内容寻址的 Evidence，并保留提供方引用、源 Schema 版本、业务时间和原始内容 hash。
3. 重复摄入相同内容会去重；修正只追加而不覆盖先前 Evidence。
4. 缺失、未知、陈旧、冲突或 Schema 漂移的提供方数据，以显式结构化结果失败关闭，且不能制造高质量 Evidence。
5. 确定性特征快照只使用请求 as-of 时间可用的 Evidence，并保留输入 hash 和特征集版本。
6. 摄入 API 将畸形或类似 Prompt Injection 的外部 payload 作为不可信数据拒绝；引用外部文本绝不改变应用行为。
7. 测试仅使用合成数据并演示 S8、S13、S14、S15 切片。
