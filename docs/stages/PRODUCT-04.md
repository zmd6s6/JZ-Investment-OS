# PRODUCT-04 — 已授权数据供应商运行时

- 状态：`IMPLEMENTING`
- 前置条件：PRODUCT-03 已由 PR #14 合并；`ResearchProviderPort`、`DSAAdapter`、Evidence 规范化与
  Provider 设置档案已存在
- 治理规范：`INVESTMENT_OS_MASTER_SPEC.md`
- 相关 ADR：`ADR-0002`、`ADR-0003`、`ADR-0010`、`ADR-0013`、`ADR-0015`
- 安全基线：`auto_trade=false`；外部数据和页面内容均为不可信输入；不访问 DSA 私有数据库或内部模块

## 目标

将一个由所有者明确授权的数据/研究供应商经既有 `ResearchProviderPort` 接入运行时，并建立可逐个扩展的
多提供方运行时注册结构，形成可追溯、可验证且失败关闭的 Evidence 摄取路径。DSA 只是一种可替换 adapter，
并非唯一或权威来源。该阶段不改变 Portfolio、Thesis、Risk、Decision、Approval 或 Execution 的权威边界。

## 多提供方不变量

- 每个已启用数据档案对应一个明确授权的供应商端点与凭据引用；运行时按 `provider_type` 选择基础设施 adapter。
- application/domain 只使用 `ResearchProviderPort` 与版本化内部 DTO；供应商 SDK、HTTP 协议和外部 Schema
  不得越过 infrastructure。
- 一次摄取显式选择 provider；不因故障、缺数据或成本静默切换来源。未来的显式回退也必须记录尝试顺序与
  实际来源。
- 各来源独立保存溯源、Schema 版本、业务时间、内容 hash、质量和新鲜度；冲突不能以覆盖历史的方式解决。

## 可以先行的安全工作

- 盘点既有 `DSAAdapter`、规范化 DTO、Evidence 质量/新鲜度和 Provider 设置端口的可复用能力。
- 为已授权供应商的运行时健康、超时、认证、Schema 漂移、溯源、去重和失败关闭补齐应用/基础设施接线。
- 使用合成或供应商明确允许的去标识化夹具完成契约、集成和浏览器验证。

## 必须等待所有者的决定

在任何真实网络连接、凭据录入、许可接受或真实标的请求之前，所有者必须明确指定：

1. 供应商及允许使用的产品/API；
2. 许可证/账户授权状态与可访问端点；
3. 数据类别、市场范围、保留与隐私边界；
4. 可接受的测试标的或供应商提供的沙箱路径。

未获得这些决定时，系统只能保持配置为禁用或使用合成夹具；不得把未知来源的数据标记为 Evidence，
不得构造看似成功的摄取结果。

## 已确认边界与当前阻塞

2026-09-23，所有者已明确确认以下边界：

- 允许使用博查 Web Search 进行个人投资研究；
- 后续实际检索结果的本地保留期限为 365 天，并已作为数据档案配置和未来 Evidence 的 `expires_at` 生效；
- 首次真实摄取使用公开查询“宁德时代 最新公告”，最多 5 条结果。

该授权不包含自动分析编排、投资决策、投资政策变更、自动交易或未声明的查询范围。首次受限摄取已完成；
后续检索仍须显式指定查询和已启用档案。设置 API/UI 已分别显示最近连接测试与最近成功同步状态。

## 验收标准

1. 已授权供应商的配置、连接测试、健康与最近成功同步状态可通过受支持的产品 API/UI 查看，且绝不返回凭据。
2. 一个已授权的真实或供应商沙箱标的可产生带来源、可用时间、内容哈希与质量/新鲜度的可追溯 Evidence。
3. 超时、认证失败、Schema 漂移和不可用数据明确失败关闭；既有 Evidence 仍可读取，不生成伪造 Evidence。
4. 不导入 DSA 私有模块、不查询其私有数据库，且外部内容不会改变 Prompt、权限、Risk Veto、审批或交易边界。
5. 无真实 Portfolio 数据、投资政策变更、自动分析编排或交易行为。

## 所需人工决定

真实供应商选择、许可证、费用、数据保留/隐私边界和测试标的均由所有者决定。实现准备不构成对任何
数据源、真实投资数据或交易的授权。
