## Objective

Deliver an evidence-first Thesis Engine vertical slice. Each new ThesisVersion is append-only,
has deterministic semantic-diff and provenance, and keeps prior versions readable. New Evidence
may propose an impact only through explicit, deterministic conditions; it must never overwrite a
Thesis or produce a Decision, approval, execution, or live-trading behavior.

## Deliverables

- [ ] Strict ThesisVersion internal schema and pure-domain invariants for evidence references,
  version lineage, monitoring, and invalidation conditions
- [ ] Thesis create/version/diff service with append-only persistence and optimistic current-pointer
  updates
- [ ] Evidence-impact evaluation that creates a new version only for a material, evidence-backed
  change; unchanged Evidence must not create an empty version
- [ ] Deterministic monitoring and invalidation condition evaluation, including explicit BROKEN
  escalation candidates without a Decision or order path
- [ ] Time-travel Thesis reads and `/api/v1/theses/{instrument_id}` plus version-history read APIs
- [ ] Synthetic unit, integration, contract, and S5 regression fixtures
- [ ] Data lineage, status, and verification evidence

## Acceptance criteria

1. ThesisVersion records are immutable, content-addressed, unique and monotonically versioned;
   prior versions remain readable after corrections.
2. Every factual pillar, catalyst, risk, or material update retains valid Evidence references;
   missing or unavailable Evidence fails closed.
3. Semantic diff is deterministic for equal inputs and an unchanged impact cannot manufacture a
   new ThesisVersion.
4. An Evidence-backed invalidation creates a new `BROKEN` ThesisVersion and a machine-readable
   forced-review / REDUCE-or-EXIT candidate, without a Decision, approval, execution, or order.
5. Reads at a requested as-of time return only the latest ThesisVersion available then and never
   rewrite historical meaning.
6. The API rejects malformed or instruction-like payloads; fixtures are synthetic only.
7. S5 proves that old versions are unchanged and a historical decision can retain a fixed Thesis
   version reference.
