## 本轮发现并修复

| 问题 | 原因 / 影响 | 修复与证据 |
|---|---|---|
| 令牌几乎无法输入 | 横向 flex 中说明占据宽度，侧栏输入框约 30px | 原生模态窗口、独立输入行、自动聚焦、显示 / 隐藏、回车提交、Escape 关闭；390/800/1280px 真浏览器验证 |
| 不知道从哪里开始 | 静态“推荐路径”无操作入口，开始状态冒充向导 | 全页使用指南、首页任务入口、设置顺序、锚点目录；明确它不是验收进度 |
| 授权失败无下一步 | 错误只解释、不提供修复入口 | 错误可直接打开授权窗口；验证后清理旧鉴权提示，提醒手动重试，不重发写入 |
| 点击反馈跳来跳去 | 保存后强制滚到全局提示 | 取消强制滚动，统一随滚动可见的反馈；报告“查看”才定位到详情 |
| 标的搜索看似无响应 | 无加载 / 空结果反馈，旧响应可迟到 | 等待、无结果和手填指导；取消旧请求并忽略迟到响应 |
| 分析按钮误触编辑 | 行点击冒泡；不提示付费调用边界 | 阻止冒泡，启动前核对组合、费用、证据与取消边界 |
| 观察清单无分析入口 | 页面仍保留旧占位说明 | 增加分析确认与组合选择；失败保留清单，未确认不调用分析 |
| 报告不知道属于谁 / 去哪了 | 无标的名称；组合筛选隐式 | 当前档案名称辅助导航、显式范围与查看全部；历史仍固定原始标识 |
| 风险展示可能自相矛盾 | `decision.risk_veto` 表示 BUY/ADD 被拦截，不等同风险评估的 VETO | 展示以 Risk gate 为准的否决；缺评估显示未知，不展示虚假“否”；具名测试 |
| 术语和状态误导 | 凭据空框像丢失、单价单位不明、模型连接显示过期“未测试” | 中文角色、每 Token 单价、留空保留凭据、模型仅显示本页测试状态 |
| 窄屏表格撑宽整页 | Grid 的最小内容宽度与嵌套包装 | 显式 minmax(0,1fr)、长文本换行、表格内部横滚；5 个主页面 390px 无整页溢出 |
| 视觉层级单一 | 大面积同色卡片、全圆角按钮、提示挤在导航 | 深蓝 / 靛蓝主色、浅底、次级文字与可见焦点，统一表单与反馈；保留独立安全提示 |
