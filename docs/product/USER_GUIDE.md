# 页面使用指南

适用范围：当前 P6 开发版本。可管理组合、持仓和观察清单，阅读团队分析；不是完整 Beta，不会自动下单。

## 1. 直接打开本机工作台

本机默认模式无需输入开发令牌。Docker 服务启动后，双击项目根目录的 **打开投资工作台.cmd**。
启动器只选择端口绑定本机的部署，自动打开浏览器完成一次配对；不会调用供应商、改变持仓或批准交易。

同一浏览器保留 Cookie 时，会话最长 30 天，刷新、打开新标签页和 API 重启不需要重新配置。
点击导航「本机已连接」可查看说明或断开；断开会撤销服务端会话，不会删除业务数据。
清理 Cookie、使用另一浏览器或过期后，只需重新双击本地入口。不要因此更换模型或数据源 Key。

首次从普通地址进入且未配对时，页面会提示使用本地入口。多个本机部署同时运行时，维护者可使用
`uv run python scripts/open_local_ui.py --url http://127.0.0.1:端口` 明确选择；不能选择公网 / 局域网地址。

### 三种容易混淆的 Token

| 页面用词 | 用途 | 从哪里取得 |
|---|---|---|
| 本系统的写入令牌 | 仅保留给 CLI / 兼容 Bearer 模式 | 部署者配置；默认本机页面无需填写 |
| 提供方 API Key / Token | 访问模型、博查或 Tushare | 对应供应商；各自独立 |
| 模型 Tokens / 预算 Tokens | 文字处理用量与成本限制 | 是数量，不是密码 |

只有维护者显式启用旧 `bearer` 模式时，页面才保留手动写入令牌输入。它不是本机日常使用的推荐入口；
随机填写不会获得权限。远程访问仍须专门的登录、TLS 与安全审查，不因新本机会话而自动开放。

## 2. 第一次配置研究团队

1. 设置 →「模型与角色」。填写端点、模型名、提供方凭据、定价币种、版本和单价，保存档案。
2. 单价为**每个 Token** 的价格，不是每百万 Token 的报价；以供应商信息为准，不内置真实价格。
3. 显式启用模型，设为默认模型。未单独映射的角色继承默认模型；不会自动改用其他供应商。
4. 设置 →「调用预算」，核对币种和任务/每日数量及成本上限后保存。未配置时显示的输入示例不是生效额度。
5. 按需显式点击「测试模型连接」；这会调用供应商，可能计费。成功只代表当次连接测试，不代表完整分析已通过。

凭据输入框不会回填已有秘密。编辑时留空表示保留原凭据；需要更换时才填写新值。

## 3. 录入已持有的资产

1. 资产组合 → 新建组合，填写名称、记账货币和现金。
2. 选择组合，再搜索标的或手填代码、名称与市场。目录无匹配项时仍可手填。
3. 分别填写长期仓（Core）与机动仓（Tactical）数量。均价为每单位成本，不是总金额；两仓理由分别记录。
4. 保存后在「持仓一览」核对；点击持仓行可载入编辑。录入只是记账，不记录真实成交、不下单。
5. 多笔持仓可使用 CSV：粘贴 → 预览 → 修正无效行 → 必要时选择冲突策略 → 确认导入。示例是演示数据，不能当成个人持仓。

没有 Tushare Token 也可保存持仓；市值与估值是否可计算取决于分析时的有效行情。异币种缺 FX 时失败关闭。

## 4. 研究未持有标的

观察清单 → 搜索或手填 → 加入清单 →「研究资料」准备材料，已有资料时也可点「立即分析」。在启动前窗口**显式选择**组合上下文；可选择空持仓组合，
不必买入该标的。添加观察项不会创建持仓。

## 5. 发起与阅读分析

### 按需记录长期投资逻辑

1. 在研究页选择标的后，点「维护此标的的投资逻辑」；也可从顶部「投资逻辑」搜索已有标的。
2. 填写长期判断，至少一个逻辑支柱，并为每条支柱 / 催化剂 / 风险主张勾选支持资料。资料来自已入库的研究库，
   页面展示标题、摘录和来源；期限内不代表事实已核实。没有资料时先返回研究页准备，不自动抓取或调用模型。
3. 新建状态默认「未知」，可明确选择「有效」；补充失效条件、观察事项与修订原因后，点「保存投资逻辑新版本」。
   这是人工研究判断，不是政策激活或交易批准。后续状态只能按现有规则转换，已失效逻辑不能在这里快捷恢复。
4. 保存后查看版本号；「历史版本与变更」保留内容、父版本、内容摘要和语义变更。没有实质变化不制造空版本。
5. 两个页面同时编辑时，迟到保存会拒绝且保留输入；先复制需要保留的草稿，再明确重新读取最新版本、核对后整理保存，
   不自动合并。读取失败可只读重试；保存结果未知时保留当前内容，再次保存同一内容会复用请求标识核对，不重复创建版本。
   草稿仅在当前页面内存中保留，刷新或离开会丢失未保存内容；不要在结果未知时先改内容或刷新。
6. 点「准备资料／继续分析」回研究页，单独勾选资料、选择组合并确认模型费用。分析固定启动时的逻辑版本，
   后续修订不改旧报告；保存逻辑本身不启动分析。没有逻辑版本仍可研究，报告如实显示未知。

### 确认模型费用并启动

持仓或观察清单中的「立即分析」先展示确认窗口。核对标的、组合与计费说明，再点击「确认启动分析」。
启动窗口的「本次分析模型」默认沿用角色映射，也可选择一个模型用于本次八角色；不会修改设置中的全局映射。
展开「核对本次模型与定价」查看档案、模型、定价版本 / 币种 / 每 Token 单价。未配置价格不是免费，仍会由预算门禁拒绝。
修改配置后请点「重新读取模型配置」再核对；确认摘要已过时会明确拒绝，不替你接受新的价格或换用模型。
入队后模型 / 定价固定，改角色映射不改变该任务；修改 / 停用对应档案会使任务失败关闭。已发出的调用可能仍完成并计费。
使用已入库证据，**不会因为启用数据源而自动抓取新闻**。

### 按需选择本次行情

启动窗口的「本次行情来源与顺序」默认不读取行情，不要求先补 Tushare Token；已启用也不会自动调用。
有行情档案时，可勾选并「上移 / 下移」确认本次先后顺序；只在前一源失败或缺价时尝试已选下一项，可能产生供应商费用。
未选来源、博查和合成价格不加入；「清空行情选择」恢复不读取。「重新读取行情配置」会清空本次选择，需要重新核对。
配置在确认后变化、档案停用或凭据不可用会明确停止，不私自换源。执行中发现凭据问题前，模型可能已经计费。
当前生产行情类型只有 Tushare，可配置多个档案；不是任意名称的数据源都已支持。研究文本仍单独准备。
没有有效行情仍可阅读研究意见，但缺价 / 缺 FX 不会伪造完整估值、仓位或买入数量。

### 先准备研究资料

1. 持仓或观察清单的「研究资料」会带入标的；也可从顶部导航进入，再搜索本地目录。
2. 明确选择一个已启用、已配置凭据且支持研究检索的数据源。当前生产适配器支持博查；UI 根据服务端能力显示，
   不把 Tushare 行情档案当成新闻搜索。以后增加适配器可复用同一页面。
3. 核对「公开查询内容」和结果条数。只有查询文字会发送给供应商，不附带持仓、成本或现金。不要输入私密信息。
4. 勾选确认后点「获取资料预览」。这一步可能按供应商规则计费；候选先保存在受保护的预览中，**未进入分析证据库、不会调用模型**。
   逐条核对标题、摘录、来源与时间，再勾选候选。只有明确选择的内容才能保存；确认窗口为 10 分钟，过期不会自动重查。
   可点「仅保存所选资料」，或点「保存所选并继续分析」打开下一步确认。保存是整批事务，失败不部分入库。
   响应中断时先点「找回原预览（不重新查询）」；刷新页面也按地址里的预览 ID 恢复。不自动重发付费查询。
5. 在下方核对来源、获取渠道、摘录、新鲜度、观察 / 可用 / 入库 / 到期时间和证据 ID。刷新资料只读本地库。
   搜索线索仍为不可信输入、来源级别 OTHER；摘录不代表已抓取网页全文，也不证明文章与标的一定相关。
6. 在已存资料中勾选「用于本次分析」，再点「选择组合并分析」，单独确认组合与模型费用。保存候选后会选中本次保存的证据，仍可调整。
   该入口只使用你明确选择的证据 ID，不偷偷补入其他资料；最多 50 条。过期、尚未可用、跨标的或缺失的选择会整批拒绝，
   可刷新核对，必要时「清空分析选择」后重选。持仓 / 观察清单的旧「立即分析」入口仍兼容读取最近可用资料，窗口中会说明区别。
7. 报告展开「本次分析输入快照」，可核对实际证据 ID、hash、来源、业务时间、当时组合与政策标签。
   快照在调用模型前保存，成功 / 失败都保留，后续资料或持仓变化不会改写。旧报告没有新版快照会如实提示，不追补。
   「本次固定的模型与定价」展示各角色提交时的档案 / 模型 / 定价版本 / 单价与摘要，不是当前设置；团队意见中的模型为提供方实际返回值。

研究资料预览一次只调用所选来源。想补充另一个已授权研究来源，重新选择并显式确认；不做研究源自动聚合。
这与分析窗口中明确排序的结构化行情来源不同。
缺证据会明确失败，不能用合成材料冒充真实研究。博查是文本来源，不是行情；无需 Tushare Token 即可准备研究材料。

页面确认后先保存后台任务，立即打开带运行 ID 的「分析运行」。可以离开页面、刷新或稍后回来，Worker 会继续处理。
详情按实际事件展示第一轮、冲突检测、第二轮、组合经理、风险、估值 / 仓位及最终建议，不用时间模拟百分比。
排队只表示任务已保存；长时间不开始应检查 Worker，不要反复启动。完成表示流程结束，不等于风控通过或可以买入。

任务状态与阶段历史分别读取：即使历史暂时不可读，状态仍可更新。列表、报告或阶段历史一次读取超过 15 秒会显示中文提示，
不会一直占住按钮；这个期限仅针对页面读取，不代表后台分析已停止或失败。
先点「重试读取报告」或「刷新任务进度」核对原记录，只读取本地数据、不新建分析、不重新调用模型。
阶段历史读取失败时保留已显示的事件；不要把「重新发起新运行」当作刷新，它会新建记录且可能再次计费。

「请求取消」会先说明费用边界并要求确认：排队任务立即取消，运行中任务在下一阶段边界停止。
已经发出的供应商请求可能继续完成、修复与计费；取消不删除历史、不退款，也不撤回任何外部请求。

排队任务在 Worker 重启后继续；已执行任务若进程中断，会标为失败且不自动重放付费调用。
失败 / 已取消的新版任务可以「重新发起新运行」：核对可能再次计费后，沿用原证据 ID，按新时点重新验证有效性，
读取当前组合、政策和模型角色映射并重新固定，创建带原运行关联的新记录，不改写旧报告；不自动沿用旧单次模型选择。需要另选模型时从研究 / 持仓入口重新确认。
行情则保留原来源 ID 和顺序，重新验证并固定当前档案；停用 / 删除时拒绝，不加新来源。需要改来源请从研究 / 持仓入口重新选择。
资料过期需先准备新资料，不会悄悄替换。旧排队任务未固定模型时会明确失败，请核对后新建，不自动授权当前模型。
网络中断后先按运行 ID 核对；同一未确认的提交会复用请求标识，但不会自动重发请求。旧同步入口的报告没有新版阶段事件，页面如实说明。

报告阅读顺序：

1. 看流程状态与数据限制：成功只代表流程完成，不等于可以买入。
2. 看风险门、否决与政策版本。TEST_DEFAULT 是测试政策，不是真实投资授权。
   可展开「政策与运行规则版本 · 只读快照」，核对当时政策 ID / 版本 / 内容摘要、实际限额、测试公式与各角色 Prompt 摘要。
   首页「投资政策 · 只读审阅」展示当前选中组合的当前政策；报告展示运行当时的快照，两者在后续政策修订后可以不同，历史不会被覆盖。
   新运行还可核对独立测试策略的 ID、版本、内容摘要与实际源码指纹。DRAFT（未批准）表示只登记测试工件，并未激活策略；旧报告未记录身份时不补写。
   当前公式仍是工程测试版，即使政策显示 ACTIVE，也不会因此给出新增买入 / 加仓授权。这里只读审阅，勾选“已阅读”不是批准或激活。
   若提示固定策略 / 代码校验失败，原任务没有自动改版本或调用模型。先核对服务部署；服务源码热改后需运维重启，再明确发起新运行，不能靠更换 Token 解决。
3. 看团队观点、冲突；展开完整观点、证据引用、假设和未知项。
   「投资逻辑 · 固定版本」展示已保存的长期逻辑、支柱、观察 / 失效条件与版本标识，不是本轮模型自动创建的结论；后续修改不会改变旧报告。
   没有可用版本时显示“投资逻辑：未知”，不默认为有效，旧报告不追补。支持资料陈旧时不据此增加暴露；BROKEN 持仓的分仓减仓候选只要求复核，不是批准或成交。
4. 看估值与仓位来源；展开「行情来源实际尝试」核对档案、顺序、成功 / 无数据 / 失败及精确报价、币种、时点，第二档起标记降级。
   「本次分析输入快照」还保留当时选择顺序。缺行情时不编造市值或买入数量；旧报告未记录时不会拿当前设置补写。
   新运行的「行情调用记录」独立保存：进入来源适配器前保存调用意图，返回后追加结果，取消后也可查看。
   只有意图而无结果时显示“结果未知”；这不证明供应商已经收到请求，也不表示没有计费。旧报告不追补。
   「重新读取行情记录」仅刷新已保存记录，不重新调用行情或模型。供应商费用仍以供应商账单为准；这里不是逐条 HTTP 计费账单。

报告默认按当前选择的组合筛选；找不到其他报告时，点击「查看全部组合报告」。名称来自当前档案，仅作导航，
不会改写历史分析快照。标的已移除或名称查询失败时保留关联标识。

### 核对实际保存的研究记录

报告的「研究主表与决策关联」中，点「查看研究主表记录」。这一步只读本地数据库，不再调用模型或数据源。
新版完成运行可核对委员会 ID、每个角色的 AgentRun / Opinion ID、实际开始结束时间、模型 / Prompt 摘要、事实与证据引用，
以及 Risk ID、内容摘要、历史评估 / 到期时间、硬 / 软风险和解除条件。
组合经理与风险经理是委员会后的评估，不是第三轮辩论；失败角色明确显示资料不足，不冒充有效观点。

Risk 的「未知」不表示通过，历史「通过」和历史有效期也不是当前交易授权。
正式 Decision 尚未创建：测试策略登记不等于批准，正式政策 / 策略与完整估值、仓位版本链仍未收口；当前仍是影子建议，不是待审批、获批或成交。
旧运行没有本版关联时如实提示，不根据报告摘要或当前配置补造主表；读取失败可点按钮只读重试，保留已显示内容。
若运行报「研究主表保存失败」，不会同时展示成功报告；已发模型调用可能计费，先核对运行与费用，不自动重跑。

### 从团队报告整理人工投资逻辑

在成功分析详情点「将团队观点整理为投资逻辑草稿」。只读取已保存的研究主表，不再调用模型或来源；旧摘要缺少记录时会明确提示。
先看当时风险门、未知项和证据出处；模型观察不等于已核实事实，也不代表团队共识。默认不勾选任何观点。

1. 勾选需要核对的观察（最多20条），点「将勾选观点加入编辑草稿」。
2. 页面保留原摘要和逻辑状态，只把新观察加入“受挑战”支柱；完全重复内容不重复加入。
3. 人工整理长期判断、核对逐条引用与失效条件，再点「保存投资逻辑新版本」。加入草稿本身没有保存，离开页面未保存的文字不会自动恢复。
